## 3. 练习页构成（全部由生成器产出，不手改 HTML）

- **客观题 6 道 = 4 单选 + 2 填空**：两类都提交后统一判分并给解析，可重做；填空按去首尾空格、去成对引号归一化比对，答案唯一。
- **程序任务**：学生 IDLE 写码运行 → 粘贴输出核对；归一化比对（逐行 strip 空格/制表符/全角空格、去末尾空行）；粘贴含 `Traceback` 判定为报错，给专属提示不判通过。
- **三级提示**：思路 → 步骤 → 局部代码；第 3 级只给关键 1–2 行；记录使用次数。
- **格式检查（不判分）**按钮：中文引号、`if/elif/else/for/while` 行尾冒号、缩进混用、`&&`/`||`、圆括号配对。
- 每讲任务数：第 01 讲 2 基础 + 1 选做；第 02 讲 2 基础 + 1 选做；第 03 讲 2 必做（判质数双算法）；第 04 讲 2 必做（批处理分解 + 筛素数）；第 05 讲 1 个模拟演练核对任务。

## 4. 网页规范

- 单文件 HTML，CSS/JS 内嵌，零外部请求（无 `http://`、`https://`、`<script src=`、`<link `）；JS ≤ ES2017（禁 `?.`、`??`、`flat`、`fromEntries`）；DOM 写入用 `textContent`。
- **localStorage 键名前缀 `ds`**：学习记录 `dsNN_practice_v1`（NN = 讲次两位），代码草稿 `dsNN_draft_T{n}_v1`；与 `pyNN`、`ck` 系列互不冲突；读写全部 try/catch，不可用时顶部横幅提示，页面功能不受影响。
- 网页不执行 Python；不提前展示完整答案；不登录、不上传任何数据。
- 字号：正文 ≥ 16 px，代码 14 px 等宽；支持草稿导出 `.py`、学习记录导出 `.txt`。

## 5. 生成器约定

- `课程/工具/生成练习页.py` 是 5 个练习.html 的唯一内容源：题目数据（客观题、任务、提示、参考解法 `REF`、预期输出 `expect`）全部内嵌在数据区。
- 改题只改数据区后重新生成（无参数 = 全量重生成 5 页）；**绝不手改任何 HTML**。
- `--verify`：对全部任务的 `REF` 实际运行，比对归一化输出与 `expect` 逐字一致。
- `--selftest`：归一化、Traceback 判定、填空归一化、单选 value 互异、HTML 转义等引擎用例自检。

## 6. PPTX 课件规范

- 16:9；10–14 页/讲；字体微软雅黑 + Consolas；生成时显式声明东亚字体（`a:ea`）防中文缺字。
- 字号：标题 ≥ 28 pt，正文 ≥ 18 pt，代码 ≥ 14 pt；代码逐步出现，不整页贴大段。
- **教师内容（完整答案代码、讲稿）只进演讲者备注**；正文页可直接发学生。
- 标题字号下限同样适用于生成脚本中的所有占位文本。

## 7. 代码规范

- Python 3.9 兼容，仅标准库；不用类、推导式、生成器、`match`；`while` 允许（试除必需）。
- 代码带中文注释，变量名英文；计时只用 `time.perf_counter()`。
- 每个 `.py` 在讲次文件夹内实际跑通；教师参考答案必须实际运行并比对输出。
- 大数相关：整数任意精度是 Python 默认行为，教学代码不写溢出防护。

## 8. 学生包与教师包

- **学生包**：`练习.html` + `代码/` 中 demo 与 task + `数据/` + `课件.pptx`（正文页可直接发放）。
- **教师包**：学生包 + `教案.md` + `工具/生成练习页.py` + `answer*.py` / `参考*.py` + 实验记录表参考值 + 模拟卷评分标准。
- 分发前检查：学生包无 `answer*.py`、`参考*.py`、`教案.md`、`工具/`；练习页正文与课件正文页无完整参考答案。

## 9. 验收清单

1. `python 课程/工具/生成练习页.py --verify` 与 `--selftest` 全绿。
2. 全部 `.py` 实跑通过（PYTHONIOENCODING=utf-8，stderr 为空），输出与练习页 expect 一致。
3. 5 个练习页 grep：无外部请求、无 ES2017 以上语法、无 `py`/`ck` 撞键、无答案泄漏。
4. PPTX 读回断言：页数 10–14、每页有备注、正文页无「参考答案」。
5. 第 03、04 讲实验：三档数字素性已验证、耗时为本机实测、实验二两方案输出 diff 一致。
6. 素材索引 15/15 覆盖；中文排版（全角标点、中英文数字交界半角空格、破折号 `--`）。
7. 刷新后练习页记录保留；教师内容不进学生可见面。
