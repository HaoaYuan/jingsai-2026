> 班型：初中组备赛队（**完全零基础**，2026-11-16 确认）
> 课时：40 分钟；配套课件 `课件.pptx`、练习页 `练习.html`

## 教学目标

1. 认识并会照打六大句型：输出 `print()`、变量 `n = 7`、输入 `int(input())`、判断 `if/else`、循环累加 `for` + `total`、函数 `def` + `return`。
2. 能模仿示例改出 T1（和与差）、T2（奇偶判断），知道每个句型在分解程序里的位置。
3. 见过一次大数演示（`2 ** 100`），知道「Python 算大数不吃力」--建立学下去的信心。

## 重点难点

- 重点：六大句型的「照打」--先会打出来，再谈理解；判断句型的冒号与缩进。
- 难点：input 读进来是「文字」不是数（必须 int）；缩进 4 格是语法不是美观。
- 认知负荷控制：每句型只给一个最小例子 + 一行跟做，不展开变体；函数句型只求「看得懂、会调用」，不求独立设计。

## 板书设计

```
六大句型 = 分解程序的全部零件
1 print()    显示
2 n = 7      存值
3 int(input())  读入
4 if / else  判断
5 for + 累加  从 1 数到 n      ← 下一讲的新工具「列表」先预告、不展开
6 def + return  打包
两个铁律：行末冒号 :  |  缩进 4 格
```

## 常见错误与纠正

| 现象 | 原因 | 纠正 |
|---|---|---|
| `SyntaxError` 指向行末 | if / for / def 行末漏冒号 | 行末补英文冒号 `:` |
| `IndentationError` | 缩进不齐或混用 Tab | 循环体 / 分支体统一缩 4 个空格 |
| `TypeError: unsupported operand` | input 没转 int 就做算术 | `n = int(input())` |
| 判断永远为真 / 假 | 比较写成了 `=`（存值） | 比较用 `==`，两个等号 |
| 输出乱码或报编码错 | 用了中文引号「”「」 | 引号、冒号、括号全部用英文半角 |
| `print("2+3")` 显示 2+3 | 引号里是文字不计算 | 去掉引号：`print(2 + 3)` |

## 附录 A：C++ 背景学生对照表（教师参考）

> 本批学生为零基础，此附录仅供教师应对个别有 C++ 经历的学生或备课对照；课件、练习页、代码中不出现。

| # | C++ | Python | 备注 |
|---|---|---|---|
| 1 | `#include`、`int main(){}` | 不需要 | 直接写语句 |
| 2 | `cout << x;` | `print(x)` | 多个值 `print(a, b)` |
| 3 | `cin >> x;` | `x = int(input())` | input 返回字符串必须转 int |
| 4 | `cin >> a >> b;` | `a, b = input().split()` 再 int | 一行两个数 |
| 5 | `int x = 5;` | `x = 5` | 无类型声明 |
| 6 | `a / b`（整数截断） | `a // b` | Python 的 `/` 得 float |
| 7 | `a % b` | `a % b` | 相同 |
| 8 | `for (int i = 0; i < n; i++)` | `for i in range(n):` | range(n) = 0 到 n-1 |
| 9 | `while (b)` | `while b:` | 加冒号缩进 |
| 10 | `&&`、`\|\|`、`!`、`{}` | `and`、`or`、`not`、`: 缩进` | 无大括号 |

Python 整数无溢出（int 上限约 21 亿、long long 约 9.2×10^18，Python 内存够就能算）是大数分解选 Python 的核心理由；布尔输出 Python 显示 True / False，C++ 显示 1 / 0。
