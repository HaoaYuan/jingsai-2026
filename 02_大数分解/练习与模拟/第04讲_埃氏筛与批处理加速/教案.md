# 第 04 讲教案 · 埃氏筛与批处理加速

> 班型：初中组备赛队（完全零基础，已完成第 01–03 讲三版试除）
> 课时：40 分钟；配套课件 `课件.pptx`、练习页 `练习.html`
> 本讲与第 03 讲合对准评分表「算法效率探究与优化 20 分」的下半场：批处理场景 + 埃氏筛优化 + 结论句工坊

## 教学目标

1. 会手算 30 以内的埃氏筛，能把「划倍数」翻译成五步代码（建表、划 0/1、外层 √n、划倍数、数个数）。
2. 完成 T1 批处理分解（先写对）与实验二（再加速），理解「输出逐行一致才采信提速」的护栏。
3. 给实验一、实验二各写一句「条件 + 数据 + 原因」三要素齐全的结论句。

## 重点难点

- 重点：埃氏筛五步与「从 p × p 开始划」的原因；实验二的输出一致性护栏。
- 难点：flags 表的思维转换（True = 还没被划掉）；先写对再加速的顺序纪律。
- 认知负荷控制：本讲不引入新的试除变体；方案 B 只换候选来源（全试 → 只除素数），分解本体是第 02 讲旧知识。

## 板书设计

```
批处理 = 先造工具 + 再加速
埃氏筛五步：建表 → 划 0/1 → 外层 √n → 从 p×p 划倍数 → 数个数
为什么从 p×p 开始：更小的倍数早被更小的素数划过
护栏：两方案输出逐行一致，提速才可信
结论三要素：条件 + 数据 + 原因
```

## 常见错误表

| 现象 | 原因 | 纠正 |
|---|---|---|
| 筛出来全是 0 个或全是合数 | flags[0]、flags[1] 忘了划，或划倍数从 multiple = p 开始 | 从 p × p 开始；0 和 1 手动划掉 |
| 程序卡死不动 | p = p + 1 写进了 if flags[p]: 里面 | p = p + 1 在外层缩进，每个 p 都要 +1 |
| 97 输出成空（T1） | 质数边界忘 if mm > 1 | 循环后补最后因子 |
| 几行输出攒到最后 | 输出写在循环外 | 每处理完一个数立刻 print |
| 两方案输出不一致就报提速 | 没跑一致性比对 | 先 diff 再计时；不一致修算法 |
| 提速写成「快了 100 倍」 | 口径乱编 | 以现场实测为准，统一口径 2~3.5 倍 |
