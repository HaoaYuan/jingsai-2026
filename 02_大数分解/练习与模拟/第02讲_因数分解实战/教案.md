## 精讲分步脚本（8–16 分钟，双循环分步教学）

第一步只写内层 while（3 分钟）：`m = 60`、`i = 2`，写 `while m % i == 0:` 循环体两行
`print(m)`（看一眼除到几）和 `m = m // i`，跑通看 60→30→15。让学生说规律：同一个因子要除到不能再除。
第二步加外层候选循环（2 分钟）：15 除不动 2 了，i 换 3--外层 `while i * i <= m:` 把内层包进去，跑 60 得 2,2,3,5。
第三步补质数尾巴（1 分钟）：跑 7，parts 是空的--7 自己是因子，循环后加 `if m > 1: parts.append(m)`。
第四步拼输出格式（2 分钟）：`str(n)` 把数字变文字、`+` 把文字接起来、`X.join(parts)` 用「 × 」连成一串；投影 starter 第 5 步那行，逐段念。

## 板书设计

```
手算：60 → 2×2×3×5（短除法竖式）
分步搭程序：
第 1 步 内层：while m % i == 0: 反复除（m = m // i）
第 2 步 外层：while i * i <= m: 换下一个候选
第 3 步 尾巴：if m > 1: parts.append(m)
第 4 步 拼输出：str(n) + " = " + X.join(parts)
格式三查：= 两边空格 | × 两侧空格 | 末尾干净
```

## 列表三行（概念铺垫环节板书，六大句型之外唯一新工具）

```python
parts = []           # 空列表：一个空的抽屉
parts.append(2)      # 往抽屉里放一个 2
print(parts)         # 看一眼：[2]
```

## 常见错误表

| 现象 | 原因 | 纠正 |
|---|---|---|
| 程序停不下来（死循环） | 内层忘了 `m = m // i`，m 一直不变 | 检查内层循环体两行都在：先 `append` 再整除更新 |
| 一个因子都找不出来 | 外层候选从 i = 1 开始除 | 候选从 i = 2 开始（1 能整除一切，永远除不完） |
| 分解式把合数也当因子（180 = 2 × 2 × 45?） | 除完 2、3 没继续除到不能除 | 内层 while 反复除同一个 i |
| `7` 输出 `7 = `（空） | 质数没处理 m > 1 | 循环后 `if m > 1: parts.append(m)` |
| 输出 `3.5` 或报 TypeError | 更新 n 用了 `/` | `m = m // i` |
| 统计个数差 1（17 个） | 枚举上界写成 range(1, n) | 用 `range(1, n + 1)` 或 `while i <= n` |
| 最大质因数输出 180 | 直接用了 n 而不是质因子 | 用短除法最后剩下的 m |
| × 打不出来 | 中文输入法 | 从 starter 里复制 `X = " × "` 那行的字符 |
