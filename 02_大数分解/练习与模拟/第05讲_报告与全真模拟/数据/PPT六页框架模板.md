# PPT 报告六页框架模板（第 05 讲）

> 评分表「项目分析报告 20 分」原文：报告或 PPT 涵盖**设计思路、算法原理、运行结果、效率对比、优化策略和创新点**，善用图表、流程图等可视化方式解读算法，分析有条理，能体现计算思维。
> 现场只有约 30 分钟拼 PPT（见 00_课程总览 时间分配），六页框架提前练熟，比赛时只换数字和图。

## 六页框架

| 页 | 放什么 | 忌什么 |
|---|---|---|
| 1 问题理解 | 题目要求一句话 + 输入 / 输出 / 范围 / 边界四要素 | 整段抄题 |
| 2 算法原理 | 试除法为什么成立（因子成对）+ 主算法流程图 1 张 | 贴大段代码 |
| 3 实验设计 | 档位数字表 + 为什么选质数 + 计时方法（perf_counter、3 次取最小） | 只写「测了几次」 |
| 4 数据与对比 | 实测耗时表 + 1 张对比图（柱状或折线，两版同轴） + 提速倍数大字 | 表格贴满一页不解读 |
| 5 优化策略与数学原理 | O(N) → O(√N) 的量级对比 + 「因子成对」「6k±1」「埃氏筛预处理」三条原理 | 只说「优化了」不说为什么 |
| 6 创新点与反思 | 自己独有的做法（如素数表复用、边界覆盖）+ 试除法的真实边界（10^12 以上吃力） | 吹「完美解决」 |

## 每页三行检查

1. 这页有没有一个**可读的图或表**（纯文字页 = 平庸页）？
2. 有没有一句**加粗的结论**（评委扫一眼就能抓到）？
3. 数字是不是**自己实测的**（引用他人数据或编造 = 违规）？

## 常见丢分

- 6 页里 4 页都是代码截图--「可视化解读」直接丢分。
- 效率对比只写「快了很多」没有数字--「效率对比」条目丢一半。
- 没有创新点页--「创新点」字眼在评分表里明写着。
- 流程图和代码不一致（图上除到 n，代码除到 √n）--图码一致是「算法设计与实现」的加分点。
