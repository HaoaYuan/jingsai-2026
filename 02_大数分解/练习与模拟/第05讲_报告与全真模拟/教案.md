# 第 05 讲教案 · 报告与全真模拟

> 班型：初中组备赛队（完全零基础，已完成第 01–04 讲）
> 课时：40 分钟；配套课件 `课件.pptx`、练习页 `练习.html`
> 本讲对准评分表「项目理解 10 + 问题描述 10 + 项目分析报告 20 + 现场成果分享 5」--四项合计 45 分，比算法本身还多

## 教学目标

1. 记住 PPT 六页框架（问题 → 算法 → 设计 → 数据 → 优化 → 创新），知道每页放什么、忌什么。
2. 会画一张规范的试除法流程图（四种符号、是 / 否标注、图码一致）。
3. 两人都完成一次 5 分钟陈述演练，超时会自断。
4. 领到全真模拟卷，课后完成 120 分钟完整演练 + 自评。

## 重点难点

- 重点：六页框架 + 结论三要素迁移到口头陈述。
- 难点：学生在报告里「编数字」「夸效果」的冲动--本讲反复立规矩：数据真实 > 数据漂亮，超时如实记，边界如实写。
- 认知负荷控制：本讲不学新算法；流程图只画一张（优化试除判质数），陈述骨架只背一条时间轴。

## 课前准备

- 打印每队一份：`数据/全真模拟卷.md`、`数据/评分表自评清单.md`、`数据/陈述脚本骨架.md`、`数据/流程图规范与示例.md`。
- 投影翻到 PPT 六页框架页与流程图示例页。
- 教师参考：`历史训练与拓展素材/编程竞赛模拟卷.docx`（旧卷型参考）、`讲义.docx`（大数分解与 AI--报告「研究背景」素材）--备课对比用，不要求学生复习。

## 40 分钟流程

| 时间 | 环节 | 动作 |
|---|---|---|
| 0–5 | 分值算账 | 投影评分表：四项 45 分 vs 算法 20 分+15 分；「把报告当第二道编程题来做」 |
| 5–13 | 六页框架 | 逐页讲「放什么 / 忌什么」；强调每页一句加粗结论 + 至少一张图表 |
| 13–21 | 流程图实训 | 投影示例图，学生在草稿纸照规范画「优化试除判质数」；同桌互查四符号与「是 / 否」标注 |
| 21–33 | 陈述演练 | 两人一组按骨架各讲 5 分钟，计时；超时自断示范一次；抽一组全班演示，教师点评三纪律 |
| 33–40 | 模拟卷发放 | 过一遍全真模拟卷三任务与时间分配；讲自评清单用法；布置作业 |

## 板书设计

```
报告 = 第二道编程题（45 分）
六页：问题 → 算法 → 设计 → 数据 → 优化 → 创新
流程图四符号：圆角(起止) ▱(输入输出) ◇(判断·标是否) ▭(处理)
陈述时间轴：30s 开场 / 90s 算法 / 90s 数据 / 60s 原理 / 30s 收尾
铁律：数据真实 > 数据漂亮；超时如实记；边界如实写
```

## 流程图实训要点（评分「问题描述 10 分」）

照 `数据/流程图规范与示例.md` 检查四点：
1. 判断框全部标「是 / 否」；
2. 输入 / 输出用平行四边形；
3. 循环回跳箭头不能丢；
4. **图码一致**--图上除到 √n，代码就必须除到 √n（互查环节重点查这条）。

## 陈述演练纪律（评分「现场成果分享 5 分」）

1. 每页一句话主线，不回头不跳页；
2. 核心倍数口播不超过两遍；
3. 4:30 没讲完直接跳收尾。
问答 6 预案见 `数据/陈述脚本骨架.md`（埃氏筛为何快 / 数字怎么选 / O(√N) 含义 / 还能怎么优化 / 边界处理 / 分工）。

## 常见错误表

| 现象 | 原因 | 纠正 |
|---|---|---|
| PPT 六页全是代码截图 | 不会讲图 | 每页换成一个图表 + 一句结论 |
| 流程图与代码不一致 | 画完就忘 | 图码一致互查 |
| 陈述超时还刹不住 | 没练过自断 | 4:30 跳收尾，练两遍 |
| 报告数字与记录表对不上 | 报告后补写 | 报告里的数全部抄记录表 |
| 评委追问就慌 | 没做问答预案 | 6 预案角色扮演两轮 |

## 作业（赛后冲刺核心）

3. 两人分工把模拟 PPT 做成正式版，下节课 5 分钟陈述 + 教师扮演评委抽问 3 题。
