## 2. 目标 / 非目标 / 反目标

### 目标

1. **线 A（最优先）**：3 节 40 分钟课堂教案 + 「闯关地图」网页练习包（8 关 + 1 全真模拟关，客观题自动判分 + 编程任务输出核对 + 三级提示 + localStorage 进度）+ 赛前模拟安排。学生赛后能独立写出 30 行以内的 Python 基础程序、答对 Python 基础选择/判断题。
2. **线 B**：4 讲结构化课程（教案 + 练习页 + 代码/数据），补齐评分表缺口；为既有 15 份 docx 建立素材索引（**不移动原文件**）。
3. **线 C**：4 讲提优模块（教案 + 练习页 + 图库数据），覆盖 2026 评分表新增要求；**不改动 15 课既有材料**。

### 非目标

- 不重写、不顺延、不改动 `Python基础/` 15 课任何既有文件。
- 不移动、重命名、合并 `大数分解/` 既有 docx（只新增索引和新课程目录）。
- 不做任何在线服务端、不依赖网络；网页全部离线单文件。
- 网页**不执行 Python**（沿用既有「格式检查不判分 + 输出粘贴核对」模式），不引入 Pyodide/Skulpt（机房旧机性能 + 离线包体积风险；列为未来可选项）。
- 不虚构学生数据、成绩、课堂反馈。

### 反目标（出现即算失败）

- 网页在 Windows 10 旧版 Edge 上打不开、白屏或需要联网。
- 线 A 第 1 关就让零基础学生卡死（认知负荷超标、一页塞多个知识点）。
- 练习页提前暴露答案、教师答案混入学生包。
- localStorage 键名与既有 `pyNN_practice_v1` / `pyNNsup_practice_v1` 系列冲突，丢失学生旧记录。

## 3. 约束（必须遵守）

- 机房：Windows 10 + Edge（含旧版内核），普通配置，**离线**；单文件 HTML，CSS/JS 内嵌，无外部请求。

## 4. 三条线的课程设计

### 线 A：编程闯关速成包（11.10～11.30，每周 1 节，共 3 节课 + 课后闯关）

新目录：`编程闯关/`（仓库根级，与 `大数分解/` 平级）。

```text
编程闯关/
├── 00_课程总览.md          # 3 课节奏 + 课后闯关安排 + 赛前一周模拟
├── 00_制作规范.md          # 继承 Python基础 规范，写明差异（关卡制、解锁、键名前缀 ck）
├── index.html              # 闯关地图：8 关 + 模拟关，顺序解锁，通关盖章
├── 第01课_认识IDLE与print/教案.md
├── 第02课_运算与判断/教案.md
├── 第03课_循环与综合/教案.md
├── 关卡/level01.html … level08.html   # 每关单页
├── 关卡/final.html                     # 全真模拟关（限时）
└── 代码/数据（随关卡内嵌为主，文件题另配）
```

- 关卡知识点序列（每关只承载一个主知识点）：
  1. `print()` 与注释；2. 变量与字符串；3. 四则运算与 `//` `%`；4. `input()` 与类型转换；5. `if/elif/else`；6. `for` 与 `range()`；7. 字符串索引与 `len()`；8. 综合小题（读代码写输出 + 1 道完整小程序）；模拟关：限时 40 分钟，客观题 + 编程 2 题混合，模拟未知赛制。
- 每关构成：客观题 4～6 道（单选+判断，自动判分+解析）→ 编程任务 1～2 道（IDLE 写代码 → 运行 → 粘贴输出，页面归一化比对）→ 三级提示 → 「格式检查（不判分）」按钮（中文引号、漏冒号、缩进、`&&//||`、括号配对）。
- 通关规则：客观题全对 + 编程核对通过 → 盖章解锁下一关；`?unlock=1` 教师后门一键全开。
- 课堂 3 课只教主线（第 1 课：IDLE 操作 + print/变量；第 2 课：运算+input+if；第 3 课：for+综合），**课后学生能用电脑（帅张 2026-11-10 确认）→ 8 关定位为自学载体**：提示三级都写足、解析更详细，关卡页本身就是自学教材；赛前一周完成模拟关。
- 赛制未通知 → 客观题按单选+判断准备，编程按「读题写代码、核对运行结果」通用模式准备，不过度押题。

### 线 B：大数分解结构化课程（12 月比赛，4 讲）

新目录：`大数分解/课程/`，既有 docx 留在原地，新增 `大数分解/00_素材索引.md` 把 15 份 docx 映射到各讲。

```text
大数分解/
├── 00_素材索引.md          # 15 份 docx → 各讲映射表（新增，不动原文件）
└── 课程/
    ├── 00_课程总览.md
    ├── 第01讲_C++转Python速通/   # 教案 + 课件.pptx + 练习.html + 代码/
    ├── 第02讲_因数分解实战/       # 指定成分提取、分类筛选、统计输出规范
    ├── 第03讲_双算法效率对比/     # time.perf_counter、控制变量、记录表 ← 评分核心
    └── 第04讲_报告与全真模拟/     # PPT 框架 + 流程图画法 + 5 分钟陈述 + 120 分钟模拟卷
```

每讲四件套齐全（教案 + PPTX 课件 + 练习.html + 代码/数据），对齐 `Python基础/` 既有约定；PPTX 课件规范沿用制作规范 §3（教师内容进演讲者备注，正文页可直接发放）。

- 第 01 讲面向「有 C++ 底子」：语法映射对照表（`#include`/`main` → 直接脚本、`cin` → `input()`、`int a` → 动态类型、`a/b` 整除差异、`%`、整数无溢出）、差异陷阱清单、5 道翻译练习（C++ 代码 → Python）。
- 第 03 讲是评分核心（效率探究 20 分），采用**同任务对比**，避免「两组算法比的不是同一件事」的评委追问：
  - 实验一（分解单个数）：朴素试除（一直除到 N）vs 优化试除（只除到 √n）vs 6k±1 试除——三个版本同一任务；规模分档 10^6 / 10^9 / 10^12，朴素版在大档课堂内跑不完时**如实记录「未出结果/耗时超过 X 分钟」**，正对评分表「客观记录程序耗时」。
  - 实验二（分解一大批数）：逐个试除 vs 先用埃氏筛建素数表、再只除素数——埃氏筛作为预处理环节出现，两组最终任务相同（输出这批数各自的分解）。
  - 计时用 `time.perf_counter()`，控制变量（同组数字、同次数），学生填实验记录表，复杂度用「操作次数 × 单次成本」直观讲解，结论写法模板。
- 第 04 讲给 PPT 页面框架模板（问题 → 算法 → 数据 → 对比图表 → 优化策略 → 创新）+ 流程图符号规范 + 5 分钟陈述脚本骨架 + 120 分钟全真模拟卷（含评分表自评）。
- 数学边界：不进 Pollard rho、Miller-Rabin 证明；费马小定理只作「已学过、可提分」的选讲素材（既有讲义）。

  - 红线沿用总纲既有口径：阈值与编码方案必须先用生成脚本 + 变体实机验证再定稿；若某两个模板用现有特征区分不开，先合并/缩减图库类别，其次才考虑引入新特征。
