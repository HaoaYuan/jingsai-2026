> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans（本仓库非 git 仓库，台账与验证记录代替 commit）。
> 本库无 git：所有「commit」步骤替换为「台账追加一行完成记录 + 验证输出」。

**Goal:** 交付 `大数分解/课程/` 四讲四件套（教案 + PPTX 课件 + 练习.html + 代码/数据）+ `大数分解/00_素材索引.md`，对准 2026 官方评分表 7 项 100 分。

**Architecture:** 4 个练习.html 由单一内容源 `课程/工具/生成练习页.py` 生成（沿用线 A 生成器模式：数据区 + 引擎模板 + `--verify` 实跑参考解法比对 + `--selftest`）；PPTX 用 python-pptx 生成（16:9，微软雅黑 + Consolas，教师内容进演讲者备注）；既有 15 份 docx 原地不动。

**Tech Stack:** Python 3.9 兼容（标准库 only）、python-pptx 1.0.2、单文件离线 HTML（ES2017 上限）。

**Spec:** `goals/20261110-0055-three-track-courses.md` §4 线 B、§5 验收（设计已批准）。官方评分表原文已核对（`大数分解.doc`）：项目理解 10 / 问题描述 10 / 数字分解与处理 15 / 算法设计与实现 20 / 算法效率探究与优化 20 / 项目分析报告 20 / 现场成果分享 5，共 100 分；现场 120 分钟，任务三项：数字分解与处理、算法效率探究、报告 PPT。

## Global Constraints

- Python 3.9 兼容，仅标准库；不用类、装饰器、生成器表达式、`match`、第三方运行时依赖（python-pptx 仅施工侧用）。
- 练习.html：单文件、CSS/JS 内嵌、零外部请求（无 `http://`、`https://`、`<script src=`、`<link `）；JS ≤ ES2017（禁 `?.` `??` `flat` `fromEntries`）；DOM 写入用 textContent；localStorage 读写全 try/catch。
- localStorage 键名前缀 `ds`：学习记录 `dsNN_practice_v1`，草稿 `dsNN_draft_T{n}_v1`；与 `pyNN` / `ck` 系列互不冲突。
- 练习页构成：客观题 6 道 = 4 单选 + 2 填空（两类都提交后判分 + 解析）；程序任务带「格式检查（不判分）」按钮 + 输出粘贴核对（归一化：逐行 strip ` \t　`、去末尾空行；Traceback 粘贴给专属提示不判通过）；三级提示（思路→步骤→局部代码，第 3 级只给关键 1–2 行）。
- 学生可见页面不出现完整参考答案；参考答案只在生成器数据区、`answer*.py` / `参考*.py` / 教案 / 演讲者备注。
- PPTX：16:9，10–12 页/讲，微软雅黑 + Consolas，显式声明东亚字体（`a:ea`）；答案与讲稿只进演讲者备注，正文页只放任务要求与预期输出。
- 中文排版：全角标点、中英文/数字交界半角空格、破折号 `--`。
- 不移动、重命名 `大数分解/` 既有 15 份 docx；只新增文件。
- 数学边界：不进 Pollard rho、Miller-Rabin 证明；费马小定理只作选讲/报告创新点素材（指向既有 `费马小定理.docx`）。
- 本机即北京时间，时间戳用 `python -c "from datetime import datetime; datetime.now()"` 取。

## Review Focus（终审逐条核查）

1. **实验数据真实性**（评分「结论可信、数据真实」20 分）：三个档位数字 1000003 / 1000000007 / 999999999989 的素性必须脚本验证；各档优化版耗时、朴素版超时口径（>30 秒）必须本机实测，实验记录表中的教师实测值不得编造。
2. **填空题归一化唯一性**：去空格/去引号归一化后必须恰好匹配唯一答案；等价写法（如 `1000003` 与 `1_000_003`）要么都判对要么题面锁定写法。
3. **单选 value 互异**（线 A Critical 的变体）：每个单选题各选项 value 按下标生成互不相同，答案下标正确。
4. **PPTX 正文/备注隔离**：正文页不得出现参考答案代码与完整解析；用 python-pptx 读回全文断言。
5. **C++↔Python 对照表事实准确**：`/` 整数除法截断 vs Python `/` 得 float、`cin>>`、`{}` vs 缩进、int 溢出 vs 无限精度、`&&||!` vs `and/or/not`、`bool` 输出 1/0 vs True/False--错一处即教错一整班。
6. **同任务对比口径**（评分「控制变量」）：实验一三版本任务完全相同（分解同一个数、输出同一格式）；实验二两方案最终输出完全一致（实跑 diff 证明）。
