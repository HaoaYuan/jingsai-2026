第一部分 · 客观题

1. 如果把处理 n 个数据的两层嵌套循环（每层都跑 n 次）优化成只用一层循环（跑 n 次），当 n = 1000 时，内层操作大约从多少次降到 1000 次？

解析：两层各跑 1000 圈的总次数是 1000 × 1000 = 1000000（一百万次），优化成单层后只需 1000 次，相差一千倍。

2. 鸡兔同笼共 35 个头，用 for chicken in range(36): 枚举鸡的数量时，兔的数量直接写成 35 - chicken。这种做法需要几层循环？

解析：利用「总数已知」消去第二个未知数，把二维枚举降成一维枚举，1 层循环 36 次就能做完。

3. 运行： a, b = 1, 1 for i in range(4): a, b = b, a + b print(b) 输出什么？

解析：这是斐波那契递推：4 圈之后 (a, b) 依次变成 (1,2) -> (2,3) -> (3,5) -> (5,8)，所以最终 b 为 8。

4. 对列表 [5, 2, 8, 1] 从左到右做一轮相邻比较（若左边比右边大就交换），这一轮结束后列表变成？

解析：5>2 交换得 [2,5,8,1]；5<8 不换；8>1 交换得 [2,5,1,8]。最大值 8 像气泡一样冒到了最右端。

5. 判断整数 n（n >= 2）是否为质数，为什么循环除数只需要试到 i * i <= n（即 √n）就够了？

解析：若 n = a × b，如果 a 和 b 都大于 √n，则 a × b > n 矛盾，所以至少有一个因数 <= √n。

6. 用辗转相除法 a, b = b, a % b 求 48 和 18 的最大公约数直到 b == 0，依次经过的 (a, b) 是？

解析：48 % 18 = 12 得 (18, 12)；18 % 12 = 6 得 (12, 6)；12 % 6 = 0 得 (6, 0)，最大公约数是 6。

7. 二维列表 mat = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]，运行 print(mat[1][2] + mat[2][0]) 输出什么？

解析：mat[1][2] 是第 1 行第 2 列的 6，mat[2][0] 是第 2 行第 0 列的 7，6 + 7 = 13。

8. nums = [2, 2, 3, 2]，运行： for x in nums: if x == 2: nums.remove(x) 发现删不干净，最根本的原因是？

解析：删掉第 0 个 2 后，原本第 1 个 2 左移到 0 号位，循环下一步直接跳去查 1 号位的 3，从而漏掉了中间的 2。

9. 小写字母 'x' 在字母表中往后循环移动 5 位（'z' 的下一位回到 'a'），用 chr((ord('x') - ord('a') + 5) % 26 + ord('a')) 算出的结果是？

解析：'x' 是第 23 号字母（从 0 数），(23 + 5) % 26 = 2，第 2 号字母是 'c'。

10. 运行： d = {} for ch in "ababa": d[ch] = d.get(ch, 0) + 1 print(d["a"]) 输出什么？

解析：字典统计每个字符出现次数，"ababa" 里 'a' 出现了 3 次，所以 d["a"] 是 3。

11. 在 1024 个已经从小到大排好序的数中用「二分查找」找目标值（每次对比中间数排除一半），最多只需要查几次？

解析：每查 1 次数据规模减半：1024 -> 512 -> 256 -> ... -> 1，最多约 10~11 次就能锁定目标。

12. 在 Python 中，写法 a, b = b, a 可以不用第三个临时变量直接交换 a 和 b 的值。

解析：Python 会先把右边的 (b, a) 打包算好，再同时拆包赋给左边的 a 和 b，不会互相覆盖。

13. for 循环一定比 while 循环快，所以能用 for 的地方绝对不能用 while。

解析：两者只是控制循环的写法不同：固定次数常用 for，按条件停下常用 while，没有谁绝对更快。

14. 用列表 cnt = [0] * 10 配合 cnt[d] += 1 可以一次统计 0–9 十个数字各自的频次，比写十个变量更简洁。

解析：这就是桶计数（频次表）思想，用数字本身作下标直接定位计数器。

15. 解决「百钱买百鸡」时，如果公鸡、母鸡、小鸡各套一层 0 到 100 的循环，即使不优化也只需要执行 100 次。

解析：三层 0..100 嵌套总次数是 101 × 101 × 101 ≈ 103 万次；通过数量关系剪枝或消元能大幅减少次数。
