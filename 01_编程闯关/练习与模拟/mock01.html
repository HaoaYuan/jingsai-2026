第一部分 · 客观题

全部作答后点「提交判分」，全对是盖章条件之一；做错会显示解析，可重做。

1. 运行： a = 3 b = 8 t = a a = b b = t print(a, b) 输出什么？

解析：t 先暂存了 a 原来的值 3，然后 b 的 8 覆盖 a，最后把 t 里的 3 放进 b，完成两个变量的值交换，输出 8 3。

2. 表达式 (2 + 1) ** 2 - 4 的结果是？

解析：** 是幂运算（乘方）。先算括号里 2 + 1 = 3，再算 3 的 2 次方等于 9，最后 9 - 4 = 5。

3. 运行： m = 10 m = m - 3 m = m * 2 print(m) 输出什么？

解析：按从上到下顺序一步步更新：m 先变成 10 - 3 = 7，再变成 7 × 2 = 14。

4. 执行 print("2026", "11", "30", sep="-")，屏幕上显示什么？

解析：sep="-" 可以把 print 逗号之间的默认分隔符（空格）改成短横线 "-"，所以输出 2026-11-30。

5. 运行 print("得分：" + 95) 时，程序会报哪一种错误？

解析：字符串和整数不能直接用 + 相加，这是类型不匹配，报 TypeError；改成 str(95) 或用逗号分隔即可。

6. 运行： n = 12 if n % 2 == 0: print("偶") if n % 3 == 0: print("三") 输出什么？

解析：这是两个独立的 if（不是 elif），12 既能被 2 整除又能被 3 整除，所以两个条件都会成立并依次执行。

7. 某项目限高规则： if h >= 140: print("全票") elif h >= 110: print("半票") else: print("免票") 当 h = 140 时，输出什么？

解析：>= 包含等于，140 >= 140 成立，直接命中第一条分支输出「全票」，后面的 elif 不再检查。

8. 运行： ans = 0 for i in range(1, 5): if i % 2 == 0: ans = ans + i else: ans = ans - 1 print(ans) 输出什么？

解析：i=1 奇数减 1 得 -1；i=2 偶数加 2 得 1；i=3 奇数减 1 得 0；i=4 偶数加 4 得 4。

9. 运行： c = 0 for i in range(3): for j in range(4): c = c + 1 print(c) 输出什么？

解析：外层循环走 3 圈，每走 1 圈内层循环都走 4 圈，一共执行 3 × 4 = 12 次，c 最终为 12。

10. s = "ABCDEF"，执行 print(s[1:4]) 输出什么？

解析：切片 s[1:4] 含头不含尾：从下标 1（'B'）切到下标 3（'D'），不含下标 4（'E'），结果是 BCD。

11. msg = "2026 python"，运行 print("py" in msg, "Py" in msg) 输出什么？

解析：in 检查子串是否出现且区分大小写："py" 在 msg 里为 True，大写的 "Py" 不在里面为 False。

12. 当 a = 9、b = 4 时，a // b 和 int(a / b) 计算得到的结果都是整数 2。

解析：9 // 4 = 2；9 / 4 = 2.25，套一层 int(2.25) 会截断小数部分，同样得到整数 2。

13. 已知 s = "hello"，运行 s[0] = "H" 可以把字符串首字母改成大写的 "H"。

解析：Python 的字符串是不可变类型，不能通过 s[0] = ... 直接修改其中某个字符，会报 TypeError。

14. 在循环里写 print(i, end="")，所有输出会紧挨着显示在同一行，中间没有任何空格。

解析：end="" 把默认的换行符替换成了空字符串，所以每次打印后既不换行也不多加空格。

15. for i in range(10, 1): 会让 i 从 10 倒着数到 2，一共执行 9 圈。

解析：不写第 3 个步长参数时默认每次 +1，起始值 10 比结束值 1 大时，range(10, 1) 为空，循环 0 圈直接跳过。
