第一部分 · 客观题

全部作答后点「提交判分」，全对是盖章条件之一；做错会显示解析，可重做。

1. 在 IDLE 中运行当前 .py 文件，按哪个键？

解析：F5 是 Run Module（运行模块）；Ctrl + S 只是保存，不会运行。

2. 下面哪一行能在屏幕上输出「你好」？

解析：print 输出的文字要加引号；echo 不是 Python 的输出命令。

3. Python 的注释用什么符号开头？

解析：Python 用 # 写注释；// 是某些其他语言的注释符，在 Python 里是整除运算。

4. 运行下面两行代码，屏幕上输出几行？ print("a") print("b")

解析：每个 print 输出完会自动换行，所以 a 和 b 各占一行。

5. 代码 print（"你好"） 里的中文括号会让程序报错。

解析：Python 只认英文标点，中文括号、中文引号都会导致语法错误。
