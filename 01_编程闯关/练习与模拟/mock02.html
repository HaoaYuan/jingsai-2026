1. 已知 x = 15，表达式 x > 10 and x < 20 与 not (x == 15) 的结果分别是？

解析：15 同时大于 10 且小于 20，所以 and 结果为 True；x == 15 为 True，前面加 not 取反变成 False。

2. 运行： nums = [2, 4, 6] nums.append(8) nums[1] = nums[0] + nums[2] print(nums) 输出什么？

解析：append(8) 后列表变为 [2, 4, 6, 8]；接着 nums[1] 被改写为 nums[0] + nums[2] = 2 + 6 = 8，得到 [2, 8, 6, 8]。

3. 已知列表 a = [10, 20, 30, 40, 50]，运行 print(sum(a[1:4])) 输出什么？

解析：a[1:4] 取出下标 1、2、3 的三个元素 [20, 30, 40]，sum 求和得 20 + 30 + 40 = 90。

4. 表达式 list(range(10, 0, -3)) 的结果是？

解析：从 10 开始每次减 3，到大于 0 的 1 为止（不含 0 及负数），依次得到 10、7、4、1。

5. 运行： n = 1 step = 0 while n < 20: n = n * 2 step = step + 1 print(n, step) 输出什么？

解析：n 依次变为 2(1步)、4(2步)、8(3步)、16(4步)、32(5步)，32 不满足 < 20 停止，输出 32 5。

6. 运行： for i in range(1, 10): if i % 4 == 0: break print(i, end=" ") 输出什么？

解析：i 为 1、2、3 时均打印出来；当 i = 4 时 4 % 4 == 0 触发 break，立刻跳出整个循环，后面不再打印。

7. 运行： s = 0 for i in range(1, 6): if i == 3: continue s = s + i print(s) 输出什么？

解析：continue 只跳过当前这一圈后面的语句（不加 3），循环继续往下走到 4 和 5，总和 1 + 2 + 4 + 5 = 12。

8. line = "90 85 100"，运行 parts = line.split(); print(len(parts), parts[1]) 输出什么？

解析：split() 按空格把字符串拆成列表 ["90", "85", "100"]，共 3 项，下标 1 是 "85"。

9. 已知三位数整数 n = 479，想单独算出它的十位数字 7，正确的整数表达式是？

解析：479 // 10 = 47 去掉个位，再 % 10 取出 47 的末位即原十位数字 7。

10. 运行： cnt = 0 for i in range(1, 5): for j in range(i): cnt = cnt + 1 print(cnt) 输出什么？

解析：i 取 1、2、3、4 时，内层 j 分别走 1、2、3、4 圈，总次数 1 + 2 + 3 + 4 = 10。

11. 公历年份 y 为闰年的条件是「能被 4 整除且不能被 100 整除，或者能被 400 整除」。下面写法完全正确的是？

解析：百年不闰、四百年再闰：例如 1900 满足被 4 整除但被 100 整除所以不是闰年，2000 满足被 400 整除所以是闰年。

12. 写 while 循环时如果忘了更新判断用到的变量，很可能会造成停不下来的死循环。

解析：条件一直保持为 True 就会无限重复执行，写 while 必须保证每轮变量都在向结束条件逼近。

13. 执行 a = [1, 2, 3]; b = a; b.append(4) 后，列表 a 仍然只有 [1, 2, 3] 三个元素。

解析：b = a 只是给同一个列表起了第二个名字，没有复制新列表；修改 b 同样会改变 a。

14. 在 Python 3 中，round(2.5) 会遵循「奇进偶舍（银行家舍入）」，返回 2 而不是 3。

解析：Python 3 的 round 对正好处于中间的 .5 会向最近的偶数舍入：round(2.5)=2，round(3.5)=4。

15. 表达式 "apple" in ["banana", "app"] 的结果是 True。

解析：对列表用 in 是检查有没有哪个元素完全等于 "apple"；列表里只有 "banana" 和 "app"，结果为 False。
