## 教学目标

学完本课，学生应能：

1. 写出 `for i in range(1, 101):` 这样的循环，说出 range「含头不含尾」。
2. 解释累加变量为什么写在循环外、先置 0。
3. 把「读入 → 循环处理 → 按格式输出」串成一个 15 行以内的小程序。
4. 知道模拟关的 40 分钟节奏，明白赛前的自查顺序。

## 重点与难点

- **重点：**range 边界（`range(1, 101)` 不含 101）；累加/累乘器的位置和初值。
- **难点：**`range(1, n + 1)` 为什么要 `n + 1`；循环里和循环外的 `print` 输出完全不同。
- **突破办法：**投影循环表格（圈数 × i × total）逐圈填表，肉眼看到 5050 怎么来。

## 40 分钟流程

### 0–5 分钟：复习与导入

1. 请一名学生说 L06 自己是怎么「猜」出 for 写法的；教师顺着讲标准写法。
2. 快问：`range(1, 4)` 里有哪些数？（1、2、3——不含 4）
3. 板书目标：**会写循环、会累加累乘、能串综合题。**

### 5–20 分钟：新知与演示

1. **for 结构：**`for i in range(1, 101):` 下一行缩进 4 空格；range 含头不含尾。
2. **累加演示：**`total = 0` 在循环外；循环里 `total = total + i`；循环**外** `print(total)`——投影逐圈表格（i = 1, 2, 3 → total = 1, 3, 6）。
3. **累乘变式：**`result = 1`（乘法从 1 起），`result = result * i`；追问：置 0 会怎样？（全乘成 0）
4. **`range(1, n + 1)`：**想包含 n 自己就要写 `n + 1`，这是 L08 阶乘题的关键。

### 20–35 分钟：动手实践

- **任务 A（对应 L06 任务）：**1 到 100 求和输出 5050。已课后过关的学生直接做拓展：改成求 1 到 100 偶数之和。
- **任务 B（对应 L08 任务）：**读入 n 算阶乘（输入 5 输出「5 的阶乘是 120」）。串起第 1–3 课全部内容。
- **迷你限时演练（约 8 分钟，模拟 final 节奏）：**做 L07 任务 + L07 客观题，计时开始到交卷，体验「读题 → 写码 → 运行 → 粘贴核对」全流程。

### 35–40 分钟：小结与作业布置

1. 口头三连问：`range(1, 101)` 最大的数是几？累加器写循环里会怎样？想包含 n 本身 range 怎么写？
2. 讲 final 模拟关：40 分钟倒计时，10 道客观题 + 2 道编程，归零锁定；赛后对照解析自查。
3. **作业：课后完成 L07、L08 盖章；赛前一周（11.23 那周）完成一次 final 模拟关。**比赛是 11 月 30 日，别攒到最后一天。

## 板书设计

```text
第 3 课 会循环 · 会累加 · 能综合
total = 0              ←循环外，清零一次
for i in range(1, 101):    ←含头不含尾
    total = total + i      ←缩进 4 空格
print(total)           ←也在循环外！
累乘：result = 1 起，result = result * i
要包含 n：range(1, n + 1)
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| 输出 101 个数 | `print` 写进了循环里 | 结果想只要一个，`print` 就在循环外 |
| 结果是 0 | 累乘器 `result = 0` | 乘法的口袋里先放 1 |
| 少加最后一个数 | `range(1, 100)` 漏了 100 | 含头不含尾，要含 n 就 `n + 1` |
| `IndentationError` | 循环体没缩进 | for 下面一行先敲 4 个空格 |
| 粘贴核对不一致但看着像 | 多打/漏打一行、中文标点 | 逐行对，标点切英文 |
