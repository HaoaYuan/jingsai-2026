## 教学目标

学完本课，学生应能：

1. 说出 `//` 是整除、`%` 是取余，并用它们算「摆几行剩几个」。
2. 用 `int(input())` 读入整数，解释「input 拿到的永远是字符串」。
3. 写出 `if / elif / else` 分支，说出 `=` 是赋值、`==` 是比较，分支行尾要冒号、下一行要缩进。

## 重点与难点

- **重点：**`int(input())` 两步连用；`if/elif` 从上往下依次检查。
- **难点：**忘写 `int()` 导致报错或拼接出错；`= 与 ==` 混用。
- **突破办法：**让学生先运行「忘 int」的版本看到报错，再补上 `int()` 对比。

## 40 分钟流程

### 0–5 分钟：复习与导入

1. 快问快答：`print` 逗号连接会不会加空格？注释用什么符号？`7 // 2` 等于几？
2. 讲一个课后闯关的共性卡点（从提示使用记录或学生提问里取）。
3. 板书目标：**会算整除取余、会读入数字、会让程序判断。**

### 5–20 分钟：新知与演示

1. **`//` 与 `%`：**17 个像素每行摆 5 个 → 摆满 `17 // 5 = 3` 行，剩 `17 % 5 = 2` 个。强调 `/` 结果带小数、`//` 不要小数。
2. **`input` 与 `int()`：**`a = input()` 拿到的是字符串「7」，`a + 1` 会报错；`int(a)` 转成数字才能算。演示 `int("abc")` 的报错。
3. **`if / elif / else`：**分数定等级的完整演示——条件从上往下查，命中一个就跳过其余；行尾冒号、下一行缩进、`==` 才是比较。

### 20–35 分钟：动手实践

- **任务 A（对应 L04 任务）：**读两个整数，输出「两个数的和是 10」「两个数的差是 4」。先让学生故意去掉 `int()` 看报错，再修好。
- **任务 B（对应 L05 任务）：**`score = 78`，90 以上「优秀」、80 以上「良好」、60 以上「及格」、否则「不及格」，输出等级。提问：78 会命中哪个分支？为什么？
- 巡视重点：`int()` 有没有写、冒号有没有丢、缩进是不是 4 个空格。

### 35–40 分钟：小结与作业布置

1. 口头三连问：`input()` 拿到的是什么类型？判断相等用几个等号？`if` 行尾缺什么？
2. **作业：课后完成 L04–L06。**L06 是循环预习关：课堂还没讲 for，靠关卡里的三级提示自学做出来，下一课开讲对答案——做不出来不批评，做了就是赢。

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `TypeError: can only concatenate str` | 忘写 `int()`，字符串当数字算 | input 给的是文字，先 `int()` 变数字 |
| `ValueError: invalid literal for int()` | `int("abc")` 转不了 | 输入的必须是纯数字 |
| `SyntaxError` 指向 if 行 | 行尾缺冒号或用了 `=` | `if x == 10:`——冒号加两个等号 |
| 分支永远走第一个 | 条件写反或范围写错 | 从大到小排，逐个念一遍条件 |
| `/` 算出 3.5 被判不一致 | 该用 `//` 的地方用了 `/` | 题目要「整行数」就用 `//` |
