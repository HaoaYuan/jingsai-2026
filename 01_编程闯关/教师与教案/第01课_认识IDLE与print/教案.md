## 教学目标

学完本课，学生应能：

1. 独立打开 IDLE，新建、保存（`.py`）并按 F5 运行一个程序。
2. 写出 `print("...")` 和 `#` 注释，说出括号、引号必须是英文符号。
3. 给变量赋值并说出「变量是一个有名字的盒子」。
4. 遇到红字报错时，按「行号 → 最后一行红字 → 查符号」三步自查。

## 重点与难点

- **重点：**保存 → F5 的完整操作链；`print` 的英文标点。
- **难点：**中英文符号不分；看到报错就慌。
- **突破办法：**教师故意写错一次，全班一起读报错；每人至少独立改对一个符号错误。

## 40 分钟流程

### 0–5 分钟：导入

1. 说清目标：11 月 30 日编程闯关赛，通关模式 + 选择判断题，今天起每周一课 + 课后闯关。
2. 投影打开闯关地图，演示：8 关 + 终极模拟关，客观题全对 + 编程核对通过就盖章解锁下一关。
3. 板书目标：**会运行、会输出、认识报错。**

### 5–20 分钟：新知与演示

1. 演示完整操作链：开始菜单搜 IDLE → `File → New File` → 写代码 → `Ctrl+S` 保存为 `hello.py` → `F5` → 看 Shell 输出。
2. 解剖第一个程序：`print("你好，世界")`——`print` 全小写、英文括号、英文引号成对、引号不显示。
3. 注释：`#` 后面写给人看，计算机跳过。
4. 变量初识：`name = "Python"` 是「把东西放进有名字的盒子」，`print("我在学", name)` 逗号处自动加一个空格。
5. **故意犯错：**写成 `Print` 或用中文括号，运行，带全班读最后一行红字，再改对。强调：报错是计算机在告诉你哪一行有问题。

### 20–35 分钟：动手实践

- **任务 A（对应 L01 任务）：**写 3 个 `print` 输出「你好，我是闯关新手 / 这是我的第一个程序 / 闯关开始」。保存运行，对照屏幕互查。
- **任务 B（对应 L02 任务雏形）：**造 `name` 和 `hobby` 两个变量，用逗号拼接输出「我在学 Python」「我的爱好是 闯关」。
- 教师巡视顺序：先看保存成 `.py` 没有 → 再看符号 → 最后看输出。
- 先完成的学生：把输出改成自己的话，再运行一次。

### 35–40 分钟：小结与作业布置

1. 口头三连问：括号引号用中文还是英文？`#` 是干什么的？报错先看哪两样？
2. 演示课后闯关流程：打开 `level01.html` → 客观题全对 → IDLE 写码运行 → 粘贴输出核对 → 盖章。
3. **作业：课后完成 L01–L03 三关**（L03 的 `//` 和 `%` 课上只见一面，课后靠关卡提示自学，下一课开讲检查）。

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `SyntaxError: invalid character` | 中文引号、括号或逗号 | 输入法切英文，重打符号 |
| `NameError: name 'Print' is not defined` | `print` 大小写错 | Python 区分大小写，全小写 |
| 改了代码输出没变 | 没保存就 F5 | 先 `Ctrl+S` 再 `F5` |
| 文件不是 Python 文件 | 保存成 `.txt` | 文件名写全 `xx.py`，保存类型选「所有文件」 |
| `IndentationError` | 顶格行前多了空格 | 删掉行首空格 |
