# 编程闯关备赛 · 课程总纲

> 适用对象：零基础初中学生
> 课程周期：2026-11-10 ～ 2026-11-30，每周 1 节课 × 40 分钟，共 3 节；课后闯关网页自学
> 运行环境：Python 3.9.0 + 自带 IDLE，Windows 10，离线；学生课后可用电脑（家长机/机房开放时间）
> 比赛日期：2026-11-30
> 版本：2026-11-10（首版）

## 0. 一页看懂

| 项目 | 内容 |
|---|---|
| 学生起点 | 零基础：没写过代码，会用鼠标键盘 |
| 课程目标 | 独立写出 30 行以内的 Python 基础程序；答对 Python 基础单选 + 判断题 |
| 教学主线 | 课堂教主线（每课 1 个核心概念组）→ 课后闯关页自学巩固（8 关 + 1 模拟关 + 2 加练卷） |
| 终点任务 | 赛前完成全部 8 关 + 1 次 40 分钟全真模拟关；两套加练卷查漏补缺 |
| 评价方式 | 闯关盖章制，不排名；提示使用次数仅自查 |

**关键分工：课堂只教主线，闯关页是自学教材**（三级提示写足、解析详细）。课后每关的过关标准就是比赛标准的通用化：读题 → 写码 → 运行 → 结果符合预期。

## 1. 三节课安排

| 课次 | 课题 | 课堂主线 | 课后闯关 |
|---|---|---|---|
| 第 1 课 | 认识 IDLE 与 print | 新建/保存/运行 `.py`；`print()`、注释、变量与字符串启蒙；认识常见报错 | L01–L03 |
| 第 2 课 | 运算与判断 | 四则运算与 `//` `%`；`input()` 与 `int()`；`if/elif/else` | L04–L06（L06 为 for 预习，页面提示自学） |
| 第 3 课 | 循环与综合 | `for` 与 `range()`、累加/累乘、字符串索引综合、模拟题演练 | L07–L08 + 赛前完成 final |

## 2. 关卡地图（8 关 + 模拟关）

| 关 | 知识点（每关只一个主知识点） | 编程任务核心 |
|---|---|---|
| L01 | print() 与注释 | 输出指定三行 |
| L02 | 变量与字符串 | 用变量 + 逗号拼接输出 |
| L03 | 四则运算与 `//` `%` | 行列摆放换算 |
| L04 | input() 与类型转换 | 读两个数求和与差 |
| L05 | if/elif/else | 分数定等级 |
| L06 | for 与 range() | 1 到 100 求和（选做：乘法口诀行） |
| L07 | 字符串索引与 len() | 0/1 串的长度与取字符 |
| L08 | 综合 | 读入 n 算阶乘 |
| final | 全真模拟 | 40 分钟：客观题 10 道 + 编程 2 道 |
| 加练 A | 基础巩固（L1–L5） | 不限时：客观题 10 道 + 编程 3 道（身份卡 / 较大的数 / 秒数换算） |
| 加练 B | 综合模拟（L1–L8） | 不限时：客观题 10 道 + 编程 3 道（偶数求和 / 数 1 的个数 / 乘法口诀第 n 行） |
| 每日模拟一 | 60 分钟综合（L1–L8 零重复） | 限时 60 分钟：客观题 15 道 + 编程 4 道（到达时间 / 阶梯电费 / 数字串求和 / 字符串脱敏） |
| 每日模拟二 | 60 分钟进阶（逻辑/while/列表） | 限时 60 分钟：客观题 15 道 + 编程 4 道（闰年筛选 / 角谷猜想 / 成绩统计 / 回文串判断） |
| 拓展拔高卷 | 60 分钟算法思维特训 | 限时 60 分钟：客观题 15 道 + 编程 4 道（九九下三角 / 水仙花数 / 斐波那契 / 去重与第二大值） |

## 3. 赛前一周安排（11.23 那周）

1. 检查 8 关盖章状态，未过关的在课后补齐。
2. 完成一次 final 模拟关（40 分钟计时），对照解析复盘。
3. **加练 A、B 各做一遍**（不限时，建议每卷 40 分钟内完成），错题回看解析、回对应关卡补练。
4. 教师按 `ck_progress_v1` 记录点名提醒（本地查看，不上传）。
