# 2026 青少年人工智能素养提升实践活动 · 备赛知识库

本知识库面向 **2026年青少年人工智能素养提升实践活动**，按 **三大赛项 1:1 标准结构** 组织，双击根目录 `index.html` 即可离线访问全部课程、单页合集、每日 60 分钟模拟卷与拓展特训。

---

## 常用验证与重生成指令

所有工具只用 Python 3.9+ 标准库，无第三方依赖：

```bash
# 01 编程闯关：自检 + 实跑全部 29 道参考解 + 重新生成全部 16 个 HTML
python "01_编程闯关/教师与教案/工具/生成关卡.py" --selftest
python "01_编程闯关/教师与教案/工具/生成关卡.py" --verify

# 02 大数分解：自检 + 实跑全部 17 道参考解 + 重新生成全部 9 个 HTML
python "02_大数分解/教师工具/生成练习页.py" --selftest
python "02_大数分解/教师工具/生成练习页.py" --verify

# 03 图像识别：重新打包生成单页合集 图像识别全课程.html
python "03_图像识别/教师工具/生成全课程网页.py"
```
