if 让程序做选择
条件
如果……就……
条件成立，执行缩进的代码；不成立，跳过或走 elif。
if edges == 3:
    print("三角形")
比较运算
== 等于　!= 不等于
> 大于　< 小于
>= 大于等于　<= 小于等于
= 是赋值，== 才是比较。
先判断最具体的情况，最后用 else 接住其他情况。

图形识别备赛 · 第 06 讲让程序判断
根据边数判断形状



  
edges = 3

if edges == 3:
    print("三角形")
elif edges == 5:
    print("正五边形")
elif edges == 0:
    print("圆形")
else:
    print("未知")

  
运行结果
三角形
  • if 条件后面有英文冒号。
  • 下一行必须缩进，通常 4 个空格。
  • elif 可以写多个，else 最多一个。
  • edges 是变量：把 3 改成 5，走另一条路，输出正五边形。

if 的常见错误



  
坑表现
把 = 当比较if x = 3:
忘记冒号if x == 3
忘记缩进print 和 if 顶格
缩进不一致同一层用了 2 个和 4 个空格
先补英文冒号，再把下一行缩进 4 个空格。

  
报错三步
  1. 看行号：哪一行出问题
  2. 看错误类型：SyntaxError 还是 IndentationError
  3. 查符号：==、冒号、缩进
SyntaxError: expected ':'




报错不是失败，是计算机在告诉你哪一行有问题。

数据、特征与规则


数据
原始的一行 0/1 或一张网格。
特征
从数据中算出来的、能帮助判断的信息。
规则
人写清楚“满足什么条件，就归为哪一类”。


快问 1
在图像识别中，“特征”指的是什么？
A. 存储位置　B. 能帮助区分对象的信息　C. 文件名　D. 品牌
看答案
B。特征用于区分不同类别。

A. 机器学习　B. 规则系统　C. 神经网络训练　D. 数据采集
