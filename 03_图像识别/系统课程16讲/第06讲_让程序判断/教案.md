## 教学目标

学完本课，学生应能：

1. 用比较运算写出条件，知道 = 与 == 的区别。
2. 用 if / elif / else 根据给定特征输出类别。
3. 写出正确的冒号和缩进，能读懂 IndentationError。
4. 说出数据、特征、类别和规则系统的含义。

## 重点与难点

- **重点：**`if/elif/else` 的结构；`==` 比较；冒号和缩进。
- **难点：**把 `=` 当成比较；缩进层级混乱；条件顺序不合理。
- **突破办法：**先画“条件—分支”流程图，再逐行抄写；用颜色标出冒号和缩进。

## 40 分钟流程

### 0–5 分钟：复习与预测（课件 1–3）

1. 复习第 2 课：变量、索引、`len`。
2. 投影三张形状卡片：边数 3、5、0，提问“程序怎样根据边数说出名字？”
3. 让学生用“如果……就……”造句，引出条件判断。
4. 板书本课目标：比较、分支、规则。

### 5–13 分钟：讲解与演示（课件 4；出错时切到 7）

1. 比较运算：`==`、`!=`、`>`、`<`、`>=`、`<=`；强调 `=` 是赋值。
2. `if 条件:` 后面必须英文冒号，下一行缩进。
3. `elif` 可以写多个，`else` 接住其他情况。
4. **变量值决定走哪条路：**运行 `demo1_if.py`，输出「三角形」；现场把 `edges = 3` 改成 `5`，再运行——同一段代码，输出变成「正五边形」；改成 `4`，输出「未知」。点明：if 是拿变量的当前值去比对，值一变，走的那条路就变。
5. 故意把 `==` 写成 `=`，投影 SyntaxError。
6. 再演示两个特征：先判断是否封闭，再判断边数。

### 30–37 分钟：人工智能知识与客观题（课件 6、8）

先用 3 分钟讲数据、特征、类别和规则系统：

> 数据是原始的 0/1；特征是从数据中算出来的信息；类别是我们要判断的结果。规则系统就是人把“什么条件对应什么类别”写清楚。它的好处是能解释，缺点是规则要人一条条写。

再做 2 道题：

- 特征是做什么的？答案 B（帮助区分对象）。
- 人工写规则属于什么？答案 B（规则系统）。

## 板书设计

```text
让程序判断
if edges == 3:
    print("三角形")
elif edges == 5:
    print("正五边形")
else:
    print("未知")

= 赋值    == 比较
if 后面：英文冒号 + 缩进
edges 是变量：值一变，走的那条路就变
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `SyntaxError: invalid syntax` | 把 `==` 写成 `=` | 比较用 `==`，赋值才用 `=` |
| `SyntaxError: expected ':'` | if 条件后漏了冒号 | 在条件后面补英文冒号 |
| `IndentationError` | 下一行没有缩进，或缩进不一致 | 同一层统一 4 个空格 |
| 判断顺序反了 | 先写了范围大的条件 | 先判断最具体的情况，最后用 else |

### 任务 1：边数判断

```python
edges = 3

if edges == 3:
    print("三角形")
elif edges == 5:
    print("正五边形")
elif edges == 0:
    print("圆形")
else:
    print("未知")
```

### 任务 2：两特征判断

```python
edges = 5
closed = True

if not closed:
    print("不是封闭图形")
elif edges == 3:
    print("三角形")
elif edges == 5:
    print("正五边形")
else:
    print("未知")
```

### 任务 3：三条边

```python
a = 3
b = 3
c = 5

if a == b and b == c:
    print("等边三角形")
elif a == b or b == c or a == c:
    print("等腰三角形")
else:
    print("普通三角形")
```
