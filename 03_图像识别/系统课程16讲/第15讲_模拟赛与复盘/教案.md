## 教学目标

学完本课，学生应能：

1. 在 40 分钟内完成 10 道客观题和 1 道编程题。
2. 按评分表检查程序、客观题、流程图与答辩。
3. 把错题按知识不会、会但做错、时间不够分类。
4. 写出 3 项个人薄弱点和改进动作。

## 重点与难点

- **重点：**时间分配；输出模板；错题分类。
- **难点：**卡题；格式错误；复盘只对答案不找原因。
- **突破办法：**先易后难；编程先跑通一个文件；复盘必须写具体动作。

## 40 分钟流程

### 0–5 分钟：规则说明（课件 1–2）

1. 说明时间：10 分钟客观题、20 分钟编程、5 分钟核对。
2. 说明纪律：不联网、不查资料、不看参考代码。
3. 提醒：先易后难，编程先让一个文件跑通。
4. 发评分表，告诉学生最后要写 3 项薄弱点。

### 5–15 分钟：客观题（10 分钟）

- 学生在 `练习.html` 完成 10 道客观题。
- 不空题；不确定的先选一个，做完再回看。
- 教师巡视，记录集中出错的题。

### 15–35 分钟：编程题（20 分钟）

- 读取 模拟图形1–3，分类，按模板输出。
- 第 10 分钟提醒：至少让一个文件跑通。
- 第 18 分钟提醒：检查输出格式。
- 教师只回答“卡在哪一步”，不直接给代码。

### 35–40 分钟：核对与复盘（5 分钟）

- 对照评分表自评，写下 3 项薄弱点。
- 统计客观题错题类型：概念、语法、模板、时间。
- 收评分表；下节课/集训按薄弱点补练。

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| 客观题做不完 | 在一道题上卡太久 | 先易后难，单题止损 1 分钟 |
| 程序没跑通 | 想一次写完整 | 先让一个文件跑通，再套循环 |
| 输出格式错 | 空格、冒号、类别文字不一致 | 逐字对照模板 |
| 复盘空泛 | 只写“下次细心” | 写具体动作：先查什么、练哪一课 |

### 模拟编程题参考答案

```python
def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid


def bbox(grid):
    top = len(grid)
    bottom = -1
    left = len(grid[0])
    right = -1
    for i in range(len(grid)):
        for j in range(len(grid[i])):
            if grid[i][j] == "1":
                if i < top:
                    top = i
                if i > bottom:
                    bottom = i
                if j < left:
                    left = j
                if j > right:
                    right = j
    return top, bottom, left, right


def row_widths(grid):
    top, bottom, left, right = bbox(grid)
    widths = []
    for i in range(top, bottom + 1):
        count = 0
        for ch in grid[i]:
            if ch == "1":
                count += 1
        widths.append(count)
    return widths


def is_increasing(widths):
    for i in range(len(widths) - 1):
        if widths[i] > widths[i+1]:
            return False
    return True


def classify(top_width, widths):
    if top_width >= 10:
        return "正五边形"
    if is_increasing(widths):
        return "等腰三角形"
    return "圆形"


for name in ["模拟图形1.txt", "模拟图形2.txt", "模拟图形3.txt"]:
    grid = read_grid("数据/" + name)
    widths = row_widths(grid)
    label = classify(widths[0], widths)
    print(name + "  识别为: " + label)
```
