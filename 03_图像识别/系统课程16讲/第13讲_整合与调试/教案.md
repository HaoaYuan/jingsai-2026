## 教学目标

学完本课，学生应能：

1. 把读取、特征、判断、输出串成一个完整程序。
2. 按考核模板输出文件名、固定文字和类别。
3. 用换目录、换文件名的方法检查路径问题。
4. 理解误判、过拟合和准确率的局限。

## 重点与难点

- **重点：**四步流程；输出模板；路径拼接。
- **难点：**输出空格和冒号不一致；路径写死；只测一个文件。
- **突破办法：**先让一个文件跑通，再套 for 循环；把模板逐字写在黑板上对照。

## 40 分钟流程

### 0–5 分钟：复习与预测（课件 1–3）

1. 复习第 12 课：规则函数、三个样例。
2. 提问：“如果评委只运行一次程序，程序应该自己处理几个文件？”
3. 投影输出模板，让学生逐字说出文件名、空格、冒号、类别。
4. 引出整合：把四步串起来，按模板输出。

### 5–13 分钟：讲解与演示（课件 4；出错时切到 7）

1. 读取：`read_grid("数据/" + name)`。
2. 特征：`row_widths(grid)`，取首行宽。
3. 判断：`classify(widths[0], widths)`。
4. 输出：`print(name + "  识别为: " + label)`。
5. 现场演示一个文件，再套 for 循环处理三个文件；故意少打一个空格，对照模板。

### 13–30 分钟：动手实践（课件 5）

#### 任务 1：整合程序（约 10 分钟）

- 打开 `代码/task1_整合程序.py`，补全遍历和输出。

#### 任务 2：换目录测试（约 7 分钟）

#### 课堂分享（约 3 分钟）

- 请一名学生展示输出，全班逐字对照模板。
- 教师总结：整合阶段最常见的问题是路径和格式。

### 30–37 分钟：人工智能知识与客观题（课件 6、8）

先用 3 分钟讲误判、过拟合和准确率：

> 程序在 3 个样例上都对，不代表新样例也对。只用少量样例调规则，容易过拟合。准确率是对的比例，但高准确率也可能掩盖某一类的错误。要分开看每个类别，最好用平移、缩放等新样例测试。

再做 2 道题：

- 换新样例就错，最可能是什么？答案 A（过拟合）。
- 准确率的局限？答案 C（可能掩盖某类错误）。

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `FileNotFoundError` | 路径写死或当前目录不对 | 确认 `数据/` 存在，换目录时同步改路径 |
| 输出与模板不完全一致 | 空格、冒号、类别文字不一致 | 逐字对照 `图形1.txt  识别为: 圆形` |
| 只测一个文件 | 另外两个文件报错没发现 | 用 for 遍历三个文件，逐个检查 |
| 空文件崩溃 | bbox 或除法没有保护 | 读取后先判断 `if not grid:` |

### 识别程序

```python
def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid


def count_ones(grid):
    total = 0
    for row in grid:
        for ch in row:
            if ch == "1":
                total += 1
    return total


def bbox(grid):
    top = len(grid)
    bottom = -1
    left = len(grid[0])
    right = -1
    for i in range(len(grid)):
        for j in range(len(grid[i])):
            if grid[i][j] == "1":
                if i < top:
                    top = i
                if i > bottom:
                    bottom = i
                if j < left:
                    left = j
                if j > right:
                    right = j
    return top, bottom, left, right


def row_widths(grid):
    top, bottom, left, right = bbox(grid)
    widths = []
    for i in range(top, bottom + 1):
        count = 0
        for ch in grid[i]:
            if ch == "1":
                count += 1
        widths.append(count)
    return widths


def is_increasing(widths):
    for i in range(len(widths) - 1):
        if widths[i] > widths[i+1]:
            return False
    return True


def classify(top_width, widths):
    if top_width >= 10:
        return "正五边形"
    if is_increasing(widths):
        return "等腰三角形"
    return "圆形"

for name in ["图形1.txt", "图形2.txt", "图形3.txt"]:
    grid = read_grid("数据/" + name)
    widths = row_widths(grid)
    label = classify(widths[0], widths)
    print(name + "  识别为: " + label)
```
