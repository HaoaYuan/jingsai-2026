## 教学目标

学完本课，学生应能：

1. 用 with open 打开文本文件并逐行读取。
2. 用 strip() 去掉行尾换行，跳过空行。
3. 把读入的文本保存成二维列表。
4. 说出数据质量、噪声和预处理的基本含义。

## 重点与难点

- **重点：**`with open`；逐行读取；`strip()`；空行处理。
- **难点：**相对路径；忘记 strip 导致列数多 1；空行导致行数错误。
- **突破办法：**先打印 `len(grid)` 和 `len(grid[0])`，用“行数×列数”核对；把读入的前 3 行投影出来。

```text
        if line:

len(grid)     → 行数
len(grid[0])  → 列数

```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `FileNotFoundError` | 路径写错，或 .py 不在讲次文件夹 | 确认 `数据/小图形.txt` 存在，且相对路径正确 |
| 列数多 1 | 忘记 `strip()`，换行符被算进去 | 每行读入后先 `line.strip()` |
| 行数多 1 | 没有跳过空行 | 用 `if line:` 过滤空行 |
| `UnicodeDecodeError` | 文件编码不匹配 | 文本文件统一用 `encoding="utf-8"` |

## 参考答案

### 客观题

| 题号 | 答案 | 解析 |
|---:|---|---|
| 1 | B | 错误、缺失或多余的数据会干扰特征计算，结果可能变差。 |
| 2 | B | 空行会让行数、列数或统计结果出错，属于数据质量问题。 |
| 3 | A | open() 用来打开文件，再读取其中的内容。 |
| 4 | B | readlines() 把每一行作为列表的一项返回。 |
| 5 | A | strip() 去掉行首、行尾的空白字符，包括换行符。 |
| 6 | A | with 语句在代码块结束后自动关闭文件，避免忘记 close。 |

### 任务 1：读小图

```python
grid = []
with open("数据/小图形.txt", encoding="utf-8") as f:
    for line in f:
        line = line.strip()
        if line:
            grid.append(line)

total = 0
for row in grid:
    for ch in row:
        if ch == "1":
            total += 1

print("行数:", len(grid))
print("列数:", len(grid[0]))
print("1 的总数:", total)
```

### 任务 3：读三个文件

```python
names = ["图形1.txt", "图形2.txt", "图形3.txt"]

for name in names:
    grid = []
    with open("数据/" + name, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)

    total = 0
    for row in grid:
        for ch in row:
            if ch == "1":
                total += 1

    print(name, len(grid), len(grid[0]), total)
```
