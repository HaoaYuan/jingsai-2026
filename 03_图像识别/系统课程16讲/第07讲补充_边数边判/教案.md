## 教学目标

学完本课，学生应能：

1. 在循环结束后用 if/elif/else 对统计结果做判断并输出结论，说出「循环数数，循环外下结论」。
2. 用 `range(len(row))` 和记录变量 last 找最后一个 1，说出「遇到就记，后面覆盖前面」。
3. 说出特征 + 规则 = 判断，举一个规则系统的例子；知道规则可以由人写（规则系统），也可以从数据中学（机器学习，第 12 课）。
4. 能定位判断位置写错、`=` 与 `==` 混用、last 缩进错误三类问题。

## 重点与难点

- **重点：**循环外用 if 判断循环算出的结果；记录变量 last 的「覆盖」机制。
- **难点：**「判断写在循环里还是循环外」执行次数不同；`last = i` 的缩进层级。
- **突破办法：**demo2 把 print 放在循环里，投影上看见 last 被一次次覆盖成更大的位置；两个口诀上黑板（循环数数，循环外下结论 / 遇到就记，后面覆盖前面）；任务分三档，选做不占统一进度。

## 40 分钟流程

### 0–5 分钟：复习与预测（课件 1–3）

1. 复习第 6 课：`if`、`==`、`!=`、「变量值决定走哪条路」。
2. 复习第 7 课：「两个变量，两个老板」——ch 循环替你换，count 你自己加。
3. 投影一行 0/1，提问：“程序数出 1 有 14 个之后，能不能自己说出 1 多还是 0 多？”
4. 让学生先猜程序要怎么写，引出「数完再判」。

### 5–13 分钟：讲解与演示（课件 4–6；出错时切到 11）

1. **核心结构（约 3 分钟）：**循环负责逐个看，if 负责下结论。板书口诀「循环数数，循环外下结论」。强调：比较多少的 `if ones > zeros:` 写在循环**外面**——统计全部完成后再判断，整个程序只执行一次；写进循环里，每个字符都会判一次，屏幕会刷出一串结论。
2. **示例 1：数完再判（约 3 分钟）：**运行 `demo1_数完再判.py`。输出三行：两行统计、一行结论。提问「最后的 if 执行了几次？」——1 次，因为它在循环外面。指出这就是一条完整的链：**特征（1 的个数）+ 规则（比多少）+ 判断（输出结论）**。
3. **示例 2：边走边记（约 3 分钟）：**运行 `demo2_边走边记.py`。屏幕先滚出「发现 1，位置 2 / 3 / 4 / 5 …」，最后定格「最后一个 1 在位置: 26」。带着学生读：last 没有数数，它只做一件事——遇到 1 就把位置记下来，后面的 1 会把前面记的**覆盖**掉，所以循环结束时 last 里是最后一个 1。口诀「遇到就记，后面覆盖前面」。

### 30–37 分钟：人工智能知识与客观题（课件 10）

先用 3 分钟讲规则系统：

> 我们刚才写的程序分两步：先循环数出 1 的个数，这是**特征**；再用 if 比多少、说出结论，这是**规则**。特征 + 规则 = 判断。计算机按人写好的规则做判断，这样的系统叫**规则系统**，是人工智能最早的做法之一：垃圾邮件过滤器看到「中奖」「转账」这些字就怀疑是垃圾邮件；我们后面判断圆形、三角形，也是先算特征再套规则。今天的程序就是一个只有一条规则的迷你识别器。规则一定要人来写吗？第 12 课会讲：规则也可以让机器从数据里自己学，那叫机器学习。

再做 2 道快问（与练习页第 5、6 题同源，答案在演讲者备注，投影页不显示）：

- 「程序按人事先写好的规则做判断」叫什么？答案 A（规则系统）。
- 计算机识别图形的第一步做什么？答案 B（从原始数据中算出特征）。

## 板书设计

```text
边数边判
循环：逐个看        if：分情况

数完再判（特征 → 规则 → 结论）
ones / zeros -- 循环里数
if ones > zeros -- 循环外判一次

边走边记
last = i -- 遇到一个 1 就记，后面的覆盖前面的

特征 + 规则 = 判断
规则系统：规则由人写（机器学习：规则从数据学，第 12 课）
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| 判断放进循环里，屏幕刷屏 | 比较的 if 缩进进了 for | 下结论的 if 顶格写，统计完成后再判一次 |
| 想比较多少却写了 `ones = zeros` | 比较写成赋值 | 一个 = 是赋值，两个 == 才是比较 |
| last 一直是 0 | `last = i` 没缩进进 if | 把它缩进到 if 里面，遇到 1 才记 |
| `NameError: name 'zeros' is not defined` | 忘了给 zeros 初值 | 两个计数器都要先写 `= 0` |
| 对称检查结果不对 | `row[len(row) - 1 - i]` 写错 | 先口算 i = 0 时取位置 28，运算从里往外读 |

### 任务 1：数完再判

```python
row = "00111100001111000011110001100"
ones = 0
zeros = 0

for ch in row:
    if ch == "1":
        ones += 1
    else:
        zeros += 1

print("1 的个数:", ones)
print("0 的个数:", zeros)

if ones > zeros:
    print("这一行 1 比较多")
elif ones < zeros:
    print("这一行 0 比较多")
else:
    print("一样多")
```

### 任务 2：最后一个 1

```python
row = "00111100001111000011110001100"
last = 0

for i in range(len(row)):
    if row[i] == "1":
        last = i

print("最后一个 1 在位置:", last)
```

### 任务 3：对称吗（选做）

```python
row = "00111100001111000011110001100"
diff = 0

for i in range(len(row)):
    if row[i] != row[len(row) - 1 - i]:
        diff += 1

if diff == 0:
    print("这一行左右对称")
else:
    print("这一行不对称")
```

换用 `数据/对称一行.txt` 的内容 `00111100001111011110000111100` 后输出 `这一行左右对称`。
