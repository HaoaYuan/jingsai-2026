二维列表：一行一行存
二维列表
grid = [ "00100", "01110", ... ]
每个元素是一行；一行又是一个字符串。
len(grid) 是行数，len(grid[0]) 是第一行长度。
两层索引
grid[1][2]
先取第 1 行，再取这一行的第 2 个字符。
grid[0] → "00100"
grid[1][2] → "1"
行号在前，列号在后；都从 0 开始。

先取行，再取字符



  
grid = ["00100", "01110", "11111", "01110", "00100"]

print(grid[0])      # 第一行
print(grid[1][2])   # 第二行第三个字符
print(len(grid))    # 行数

  
运行结果
00100
1
5
  • grid[0] 是一整行字符串。
  • grid[1][2] 先取行，再取列。
  • len(grid) 是行数，不是像素总数。
