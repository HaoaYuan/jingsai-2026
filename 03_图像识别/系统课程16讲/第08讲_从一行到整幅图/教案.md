## 教学目标

学完本课，学生应能：

1. 用二维列表保存一幅小图像。
2. 用 grid[i][j] 按行列访问像素。
3. 用两层嵌套循环统计整幅图的 1。
4. 说出图像矩阵、坐标和分辨率的关系。

## 重点与难点

- **重点：**二维列表；`grid[i][j]`；两层嵌套循环。
- **难点：**行列顺序；`len(grid)` 与 `len(grid[0])` 的区别；内层循环缩进。
- **突破办法：**在黑板画 5×5 表格，标出行号、列号，让学生用手指出 `grid[1][2]`。

## 板书设计

```text
从一行到整幅图
grid = ["00100", "01110", "11111", ...]
grid[0]      → 第一行
grid[1][2]   → 第二行第三个字符
len(grid)    → 行数

外层：行
内层：这一行的每个字符
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `IndexError: list index out of range` | 行号或列号超出范围 | 先确认 `len(grid)` 和 `len(grid[0])` |
| 结果不对 | 行列写反 | 记住 `grid[行][列]`，行在前 |
| `IndentationError` | 内层 for 和外层平级 | 内层 for 缩进 4 个空格 |
| 每行结果累加 | 每行的 count 没有重新置 0 | 在外层循环里面、内层循环之前写 `count = 0` |

## 参考答案

### 客观题

| 题号 | 答案 | 解析 |
|---:|---|---|
| 1 | A | grid 的每个元素是一行，grid[0] 就是第一行。 |
| 2 | A | 按“先行后列”的习惯，(3, 5) 表示第 3 行、第 5 列。 |
| 3 | B | grid[1] 是第二行 "111"，再取 [0] 得到第一个字符 1。 |
| 4 | B | 外层遍历行，内层遍历这一行的每个字符。 |
| 5 | B | grid 的每个元素是一行，len(grid) 是行数。 |
| 6 | B | 外层遍历每一行，内层统计这一行的 1，再累加到总数。 |

### 任务 1：总数

```python
grid = ["00100", "01110", "11111", "01110", "00100"]
total = 0

for row in grid:
    for ch in row:
        if ch == "1":
            total += 1

print("总像素:", total)
```

### 任务 2：每行统计

```python
grid = ["00100", "01110", "11111", "01110", "00100"]

for i in range(len(grid)):
    count = 0
    for ch in grid[i]:
        if ch == "1":
            count += 1
    print("第", i, "行:", count)
```

### 任务 3：第一个 1 的坐标

```python
grid = ["00100", "01110", "11111", "01110", "00100"]

for i in range(len(grid)):
    for j in range(len(grid[i])):
        if grid[i][j] == "1":
            print("第一个 1 在:", (i, j))
            break
    else:
        continue
    break
```
