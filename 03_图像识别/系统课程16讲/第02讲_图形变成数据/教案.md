## 教学目标

学完本课，学生应能：

1. 用变量保存一行 0/1。
2. 用 len() 得到一行有多少个字符。
3. 用索引 row[i] 取指定位置，知道索引从 0 开始。
4. 说出像素、分辨率、二值图的基本含义。

## 重点与难点

- **重点：**变量赋值；`len()`；`row[i]` 从 0 开始。
- **难点：**把“第 1 个”与“索引 0”对应起来；索引越界。
- **突破办法：**在黑板画 0–28 的格子，让学生用手指点位置，再写索引。

## 40 分钟流程

1. 复习第 1 课：`print`、英文符号、保存后 F5。

4. 引出本课目标：给数据起名字，按位置取数据。

### 5–13 分钟：讲解与演示（课件 4；出错时切到 7）

1. 变量：`row = "001111..."`，等号右边是数据，左边是名字。
2. 字符串：一行 0/1 是一个字符串，每个字符都有位置。
3. 索引从 0 开始：`row[0]` 是第 1 个，`row[14]` 是第 15 个，`row[28]` 是第 29 个。
4. `len(row)` 返回字符个数；最大合法索引是 `len(row) - 1`。
5. 现场演示 `demo1_row.py`、`demo2_index.py`；故意写一次 `row[29]`，投影 IndexError。

> 图像在计算机里是一个格子一个格子存的，每个格子叫像素。100×100 就是 1 万个像素。二值图只有 0 和 1，0 是背景，1 是图形。比赛文件就是把整幅图按行存成文本。

## 板书设计

```text
一行像素
row = "00111100001111000011110001100"
len(row) = 29
row[0]   row[14]   row[28]
  ↑第1个   ↑第15个   ↑第29个
索引从 0 开始；最大索引 = 长度 - 1
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `IndexError: string index out of range` | 索引超过 `len(row)-1` | 先 `print(len(row))`，最大索引是长度减 1 |
| `SyntaxError: invalid character` | 用了中文引号 | 输入法切英文，引号要成对 |
| `row[1]` 以为是第 1 个 | 索引从 0 开始 | 第 1 个是 `row[0]`，第 2 个是 `row[1]` |
| `NameError: name 'length' is not defined` | 把 `len` 写成 `length` | Python 内置函数是 `len` |

## 参考答案

### 客观题

| 题号 | 答案 | 解析 |
|---:|---|---|
| 1 | C | 100 × 100 = 10000。分辨率描述的就是横向和纵向各有多少个像素。 |
| 2 | B | 二值图只有两种状态，常用 0 表示背景、1 表示图形。 |
| 3 | A | 索引从 0 开始，[0] 取到第一个字符 0。 |
| 4 | B | 字符串 "0110" 有 4 个字符，len 返回 4。 |
| 5 | B | 索引 0、1、2、3 分别对应 1、0、1、0，所以 s[3] 是 0。 |
| 6 | C | 长度为 3，合法索引是 0、1、2；索引 3 超出范围，报 IndexError。 |
