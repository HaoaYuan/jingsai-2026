## 教学目标

1. 用 def 定义函数，用参数接收数据。
2. 用 return 把结果交回调用处。

4. 说出识别程序的四个步骤和问题分解的好处。

## 板书设计

```text
把步骤变成函数
def count_ones(grid):
    total = 0
    ...
    return total

结果 = count_ones(grid)

输入 → 函数 → 返回
读取 → 特征 → 判断 → 输出
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| 输出 `None` | 函数忘记 `return` | 在函数最后写 `return total` |
| `TypeError: missing 1 required positional argument` | 调用时没传参数 | 写 `count_ones(grid)` |
| `IndentationError` | 函数体没有缩进 | 函数体统一缩进 4 个空格 |
| `NameError: name 'count_ones' is not defined` | 先调用后定义 | 先写 `def`，再调用 |

### 任务 1：统计函数

```python
def count_ones(grid):
    total = 0
    for row in grid:
        for ch in row:
            if ch == "1":
                total += 1
    return total

grid = ["00100", "01110", "11111", "01110", "00100"]
print(count_ones(grid))
```

### 任务 2：尺寸函数

```python
def grid_size(grid):
    return len(grid), len(grid[0])

grid = ["00100", "01110", "11111", "01110", "00100"]
rows, cols = grid_size(grid)
print(rows, cols)
```

### 任务 3：读取函数

```python
def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid

grid = read_grid("数据/小图形.txt")
total = 0
for row in grid:
    for ch in row:
        if ch == "1":
            total += 1
print(len(grid), len(grid[0]))
print("1 的总数:", total)
```
