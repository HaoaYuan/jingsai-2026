## 教学目标

学完本课，学生应能：

1. 用 for 循环逐个取出字符串中的字符，说出「循环每轮把新字符装进变量 ch，是循环替你赋值」。
2. 用 if 判断字符是否为 1，并用 count += 1 累加，说出「count 是自己加的，print 放循环里看过程、放循环外看结果」。
3. 区分原始数据和特征，说出 1 的个数可以作为什么特征。
4. 能定位计数器、缩进和 range 的常见错误，分得清 ch 和 count 谁在变。

## 重点与难点

- **重点：**`for ch in row`；`if ch == "1"`；`count += 1`；**两个变量的分工——ch 由循环换值，count 由自己加 1**。
- **难点：**`count += 1` 的缩进层级；print 放在循环外；计数器初值；**「看不见变量在变」——循环对零基础学生是黑盒**。
- **突破办法：**三步爬坡，每步都让变量「看得见」：先运行只打印 ch 的程序，看字符一个个滚过屏幕；再把 `print(count)` 放进循环，看计数器一格一格长大；最后把 print 移到循环外，只剩最终结果。全程黑板同步画格子划数。

## 40 分钟流程

### 0–5 分钟：复习与预测（课件 1–3）

1. 复习第 6 课：`if`、`==`、缩进。
2. 投影一行 0/1，提问：“不数错的话，这一行有多少个 1？”
3. 让学生先估一个数，再想“程序怎样一个一个检查”。
4. 引出 for 循环和计数器。

### 5–13 分钟：讲解与演示（课件 4–5；出错时切到 8）

三步爬坡，每一步都让变量「看得见」，学生只看不敲。

1. **第一步，循环替你换变量（约 2 分钟）：**运行 `demo1_for.py`——只有 3 行：`row`、`for ch in row:`、`print(ch)`。投影上 0 和 1 一个一个滚过屏幕，共 29 行。提问「ch 是谁？」——ch 是一个变量，循环每轮把下一个字符装进它。强调：**你从没写过 `ch = ...`，是循环替你赋值**；循环读了整个字符串，一轮读一个字符。
2. **第二步，看计数器长大（约 4 分钟）：**运行 `demo2_count.py`——加了 if 和 count，`print(count)` 在循环里面。投影滚动输出 `0 0 1 2 3 4 4 4 4 … 14`。带着学生读屏幕：数字没变的那几轮，说明当前字符是 0，count 不动；数字突然 +1，说明找到了一个 1。提问「count 是谁在改？」——是你自己写的 `count += 1`，每轮由你赋值。对比板书：**ch 循环替你换，count 你自己加**。
3. **第三步，定格最终值（约 2 分钟）：**现场把 `print(count)` 移到循环外面（去掉缩进），再运行——滚动过程消失，只剩一个 14。总结：**print 在循环里，看到的是每一步过程；在循环外，看到的是最终结果**。数 1 的个数要的是结果，所以 print 放外面。
4. **range 提示（约 1 分钟）：**运行 `demo3_range.py`——`range(5)` 产生 0–4，不包含 5。第 8 课按位置访问整幅图时会用 `range(len(row))`，今天先记住 range 从 0 开始、差一不收。

## 板书设计

```text
逐个检查像素
count = 0
for ch in row:
    if ch == "1":
        count += 1
print(count)

循环：逐个看
if：是不是 1
count：找到一个就加 1

两个变量，两个老板：
ch —— 循环替你换（每轮装进下一个字符）
count —— 你自己加 1（print 在循环里看过程，在循环外看结果）
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `NameError: name 'count' is not defined` | 计数器没有初值 | 先写 `count = 0` |
| 结果总是 0 或 1 | `count += 1` 放错层级 | 把它缩进到 `if` 里面 |
| `IndentationError` | 循环体和 if 体缩进混乱 | 同一层统一 4 个空格 |
| range 少一个数 | `range(1, 5)` 从 1 开始 | 需要 0–4 时写 `range(5)` |
| 分不清 ch 和 count 谁在变 | 把两个变量混为一谈 | ch 是循环替你换的，count 是你自己加的；把 print 放循环里看一眼就明白 |

### 任务 1：数一数

```python
row = "00111100001111000011110001100"
count = 0

for ch in row:
    if ch == "1":
        count += 1

print("1 的个数:", count)
```

### 任务 2：数零

```python
row = "00111100001111000011110001100"
ones = 0
zeros = 0

for ch in row:
    if ch == "1":
        ones += 1
    else:
        zeros += 1

print("1 的个数:", ones)
print("0 的个数:", zeros)
```

### 任务 3：第一个 1

```python
row = "00111100001111000011110001100"

for i in range(len(row)):
    if row[i] == "1":
        print("第一个 1 在位置:", i)
        break
```
