for 循环：一格一格看
循环
for ch in row:
把 row 里的字符一个一个取出来，每次放进 ch。
ch 是变量——你没写过 ch = ...，是循环替你换值。
循环次数 = 字符串长度。
计数
count = 0
遇到一个 1，就自己让 count 加 1。
if ch == "1":
    count += 1
先运行 demo1_for.py：看字符一个个滚过屏幕，就是循环在读字符串。

图形识别备赛 · 第 07 讲逐个检查像素
两步实验：看见变量在变



  
实验 1
print 放在循环里
for ch in row:
    if ch == "1":
        count += 1
    print(count)   # 每轮都打印
屏幕滚动：0 0 1 2 3 4 4 4 … 14
数字不动 = 字符是 0；数字 +1 = 找到一个 1。

  
实验 2
print 移到循环外
for ch in row:
    if ch == "1":
        count += 1
print(count)       # 循环结束后打印
滚动过程消失，只剩最终结果：14
数个数要的是结果，所以 print 放外面。




ch 循环替你换 · count 你自己加 —— 两个变量，两个老板。

统计一行中的 1



  
row = "00111100001111000011110001100"
count = 0

for ch in row:
    if ch == "1":
        count += 1

print("1 的个数:", count)

  
运行结果
1 的个数: 14
  • for 循环逐个取出字符。
  • count += 1 必须缩进在 if 里面。
  • print 放在循环外面，只输出一次。

循环与计数的常见错误



  
坑表现
计数器没置 0count 没有初值
count += 1 在循环外只加一次
缩进错了if 和 count 同一层
range 差一range(1, 5) 少了 0
先写 count = 0，再进入循环；count += 1 要在 if 里面。

  
报错三步
  1. 看行号：哪一行出问题

特征提取：从像素到数字


原始数据
一行一行的 0 和 1。
特征
从数据中统计出来的数字，例如 1 的个数。
用途
特征越能区分形状，后面的判断越可靠。


快问 1
统计一行中 1 的个数，这个数字可以作为什么？
A. 文件名　B. 特征　C. 像素颜色　D. 分辨率
看答案
B。它是从数据中提取的信息。
快问 2
原始数据与特征的关系是什么？
A. 特征从数据中提取　B. 完全相同　C. 特征更大　D. 无关
看答案
A。先有数据，再算特征。
