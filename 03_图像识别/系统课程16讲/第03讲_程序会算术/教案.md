## 教学目标

学完本课，学生应能：

1. 写出 Python 四则运算：`+` `-` `*` `/`，知道乘是 `*`、除是 `/`，不接受 `×` `÷`。
2. 说出 `/` 的结果永远带小数：`7 / 2` 得 `3.5`，`10 / 2` 得 `5.0`。
3. 用「摆满几行、剩下几个」解释 `//` 整除和 `%` 取余：`17 // 5` 得 `3`，`17 % 5` 得 `2`。
4. 用 `n % 2` 的结果判断奇偶（余 `0` 偶数、余 `1` 奇数）。
5. 用 `n // 每行个数` 和 `n % 每行个数` 把第 n 个像素换算成第几行第几列。
6. 给变量起合法且见名知义的名字：只用字母数字下划线、不数字开头、不用 `print` `if` 等关键字。
7. 知道计算机里只认 0 和 1，所有数据最后都变成二进制（为第 4 课铺垫）。

## 重点与难点

- **重点：**`//` 是「摆满几行」（商），`%` 是「剩下几个」（余数）；`/` 的结果带小数；变量名见名知义（`rows` `left` `n`）。
- **难点：**把「第 n 个像素在第几行第几列」抽象成 `n // 每行个数` 和 `n % 每行个数`；接受 `10 / 2 = 5.0` 而不是 `5`。
- **突破办法：**先用板书格子或像素卡片真分一遍 17 个像素，每行 5 个，数出 3 行剩 2 个，再写代码；`10 / 2 = 5.0` 让学生先惊讶再解释「除法的结果一律带小数，这是规矩」。命名规则用「好坏对照」讲：`a` 看不出是什么，`rows` 一眼明白。

## 40 分钟流程

### 0–5 分钟：复习与预测（课件 1–3）

1. 复习第 2 课：变量、索引从 0 开始、`len()`。
2. 提问衔接：「计算机认识数字吗？会不会算术？」
3. 预测：投影 `print(7 / 2)`，让学生先猜结果（常见猜测：3、4、3.5、3 余 1）。
4. 运行验证，揭示本课目标：**让程序会算术，学会两个新符号 `//` 和 `%`。**

### 5–13 分钟：讲解与演示（课件 4–7）

教师现场操作，学生只看不敲。

1. **四则运算怎么写：**`+` `-` 照旧；乘是星号 `*`，除是斜杠 `/`；`×` `÷` 在 Python 里不存在。
2. **重要规矩：**`/` 的结果一律带小数。运行 `demo1_四则运算.py`：`7 / 2` 得 `3.5`，`10 / 2` 得 `5.0`。强调：`5.0` 不是错，是除法的规矩；小数是什么，下一课专门讲。
3. **分像素情境：**17 个像素，每行摆 5 个。板书格子图，和学生一起数：摆满 3 行，剩 2 个。
4. **两个新符号：**
   - `17 // 5` 得 `3`——摆满几行（只留商，砍掉余数）；
   - `17 % 5` 得 `2`——剩下几个（只留余数）。
5. 运行 `demo2_整除与取余.py` 验证。
6. **应用 1，看奇偶：**任何数 `% 2`，余 `0` 是偶数，余 `1` 是奇数。口算 `7 % 2`、`8 % 2`。
7. **应用 2，找位置：**一行 10 个像素，索引 23 的像素在哪里？`23 // 10` 得 `2`（第 3 行，从 0 数），`23 % 10` 得 `3`（第 4 列，从 0 数）。运行 `demo3_找位置.py`。点明：第 8 课处理整幅图时全靠这两个式子。

## 板书设计

```text
四则运算：  +   -   *   /        （乘是 *，除是 /）
7 / 2  = 3.5      10 / 2 = 5.0   （/ 的结果一律带小数）

17 个像素，每行 5 个：
17 // 5 = 3      ← 摆满几行（商）
17 %  5 = 2      ← 还剩几个（余数）

第 n 个像素（一行 10 个）：
n // 10  → 第几行
n %  10  → 第几列

变量名：字母数字下划线，不数字开头，不用 print / if
rows = 23 // 6   ✓ 一眼明白        a = 23 // 6   ✗ 看不出是什么
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `10 / 2` 得 `5.0`，学生以为错了 | `/` 的结果一律带小数 | 不是错，是规矩；要整数商才用 `//` |
| `17 % 5` 写成 `17 % 5` 却得 `3` | 和 `//` 记反了 | `//` 砍掉余数留商，`%` 砍掉商留余数 |
| `SyntaxError: invalid character '×'` | 用了中文乘号 | Python 只认 `*` 和 `/`，输入法切英文 |
| `n // 10` 和 `n % 10` 结果写反 | 行列概念不清 | 先想「摆满几行」是行，「剩下几个」是列 |
| `23 // 10 = 2`，学生说在第 2 行 | 忽略从 0 数 | 索引从 0 数，`2` 是第 3 行；比赛数据一律从 0 数 |
| `SyntaxError: invalid decimal literal` | 变量名数字开头（如 `3rows`） | 名字只能字母下划线开头，数字不能打头 |
| `print` 当变量名用，报错怪异 | 用了 Python 占用的词 | 换个名字，`print` 这些词是 Python 自己的 |

## 参考答案

### 客观题（课件 14–15 页）

| 题号 | 答案 | 解析 |
|---:|---|---|
| 1 | B | 乘是 `*`，除是 `/`；`÷` 和 `×` 不是 Python 符号，中文输入法下容易打错。 |
| 2 | B | `/` 的结果一律带小数，`7 / 2 = 3.5`。 |
| 3 | B | `//` 只留商：5 × 3 = 15 摆满 3 行，砍掉余数 2，所以是 3。 |
| 4 | B | `%` 只留余数：17 − 15 = 2，所以是 2。 |
| 5 | C | `n % 2` 余 0 是偶数、余 1 是奇数；其余三个式子得不到「余几」。 |
| 6 | A | `27 // 10 = 2`，索引从 0 数，所以是第 3 行、索引意义上的第 2 行；题目问「从 0 开始数的第几行」，答案是 2。 |

### 任务 1：分像素

```python
rows = 23 // 6   # 3 摆满几行
left = 23 % 6    # 5 还剩几个
print(rows, left)   # 3 5
```

### 任务 2：找位置

```python
n = 27
print(n // 10)   # 2 第几行
print(n % 10)    # 7 第几列
```

### 任务 3：奇偶观察（选做）

```python
print(0 % 2)     # 0
print(1 % 2)     # 1
print(7 % 2)     # 1
print(8 % 2)     # 0
print(100 % 2)   # 0
# 发现：余 0 是偶数，余 1 是奇数
```
