## 教学目标

学完本课，学生应能：

1. 计算图形的面积和外接框。
2. 计算填充率和行宽序列。
3. 比较三个样例的特征，指出哪个特征最能区分类别。
4. 理解特征有效性，知道特征不是越多越好。

## 重点与难点

- **重点：**面积、外接框、填充率、行宽序列的计算。
- **难点：**外接框边界初值；高度宽度要 +1；空图除零。
- **突破办法：**先让学生在打印出的网格上手动标出上下左右边界，再写代码。

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| 外接框总是 0 或 -1 | 边界初值写反 | top/left 取最大，bottom/right 取 -1 |
| 高度宽度少 1 | 忘记 `+1` | 高度 = 下 - 上 + 1 |
| `ZeroDivisionError` | 空图或没有 1 | 先判断外接框是否存在 |
| 填充率小数太长 | 直接 print 浮点数 | 用 `round(x, 3)` 保留 3 位 |

### 任务 1：面积与外接框

```python
def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid


def count_ones(grid):
    total = 0
    for row in grid:
        for ch in row:
            if ch == "1":
                total += 1
    return total


def bbox(grid):
    top = len(grid)
    bottom = -1
    left = len(grid[0])
    right = -1
    for i in range(len(grid)):
        for j in range(len(grid[i])):
            if grid[i][j] == "1":
                if i < top:
                    top = i
                if i > bottom:
                    bottom = i
                if j < left:
                    left = j
                if j > right:
                    right = j
    return top, bottom, left, right


grid = read_grid("数据/图形1.txt")
print("面积:", count_ones(grid))
print("外接框:", bbox(grid))
```

```python
                    left = j
                if j > right:
                    right = j
    return top, bottom, left, right


def fill_ratio(grid):
    top, bottom, left, right = bbox(grid)
    height = bottom - top + 1
    width = right - left + 1
    return count_ones(grid) / (height * width)

for name in ["图形1.txt", "图形2.txt", "图形3.txt"]:
    grid = read_grid("数据/" + name)
    print(name.replace(".txt", "") + ":", round(fill_ratio(grid), 3))
```

### 任务 3：行宽序列

```python
def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid


def count_ones(grid):
    total = 0
    for row in grid:
        for ch in row:
            if ch == "1":
                total += 1
    return total


def bbox(grid):
    top = len(grid)
    bottom = -1
    left = len(grid[0])
    right = -1
    for i in range(len(grid)):
        for j in range(len(grid[i])):
            if grid[i][j] == "1":
                if i < top:
                    top = i
                if i > bottom:
                    bottom = i
                if j < left:
                    left = j
                if j > right:
                    right = j
    return top, bottom, left, right


def row_widths(grid):
    top, bottom, left, right = bbox(grid)
    widths = []
    for i in range(top, bottom + 1):
        count = 0
        for ch in grid[i]:
            if ch == "1":
                count += 1
        widths.append(count)
    return widths

def is_increasing(widths):
    for i in range(len(widths) - 1):
        if widths[i] > widths[i+1]:
            return False
    return True

for name in ["图形1.txt", "图形2.txt", "图形3.txt"]:
    grid = read_grid("数据/" + name)
    widths = row_widths(grid)
    print(name.replace(".txt", "") + ":", widths[0], widths[len(widths)//2], widths[-1], is_increasing(widths))
```
