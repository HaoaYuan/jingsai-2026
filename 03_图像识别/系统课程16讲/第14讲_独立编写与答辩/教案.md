## 教学目标

学完本课，学生应能：

1. 不查看参考代码，从空白文件写出完整识别程序。
2. 画出包含读取、特征、判断、输出的流程图。
3. 用 1 分钟说清程序依据和局限。
4. 对照检查表定位自己的薄弱环节。

## 重点与难点

- **重点：**独立完成四步程序；流程图；答辩结构。
- **难点：**离开提示后忘记步骤；能写但讲不清；不敢说局限。
- **突破办法：**先让学生在纸上写四步和三条规则，再上机；答辩先写四句话，再脱稿。

## 40 分钟流程

### 0–5 分钟：说明任务（课件 1–3）

1. 明确规则：不看参考代码，可以看自己的笔记。
2. 目标：25 分钟写出完整程序，输出与模板一致。
3. 提醒：先让一个文件跑通，再套 for 循环。
4. 不会的地方先写注释，不要空着。

### 5–30 分钟：独立编写（课件 3）

- 学生从空白文件开始写；教师只回答“卡在哪一步”，不直接给代码。
- 巡视记录三类问题：读取、特征、输出格式。
- 第 20 分钟提醒一次进度；第 25 分钟停止coding，进入流程图。

### 30–35 分钟：画流程图（课件 4）

- 在纸上画：开始 → 读取 → 特征 → 判断 → 输出 → 结束。
- 判断处画菱形，分出三个类别。
- 流程图不写具体代码，只写步骤。

### 35–40 分钟：口述与互评（课件 5）

- 同桌两两互讲 1 分钟，按“四句话”结构。
- 教师抽 1–2 人全班展示。
- 收走参考代码，提醒下节课模拟赛。

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| 写不出第一步 | 只记住代码，没记住流程 | 先在纸上写四步，再写函数 |
| 能跑但输出不对 | 模板空格或冒号不一致 | 逐字对照模板 |
| 能写但讲不清 | 没有准备答辩结构 | 背四句话，不看稿 |
| 不敢说局限 | 以为说局限会扣分 | 评委更看重真实判断，不要夸大 |

### 独立编程参考答案

```python
def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid


def count_ones(grid):
    total = 0
    for row in grid:
        for ch in row:
            if ch == "1":
                total += 1
    return total


def bbox(grid):
    top = len(grid)
    bottom = -1
    left = len(grid[0])
    right = -1
    for i in range(len(grid)):
        for j in range(len(grid[i])):
            if grid[i][j] == "1":
                if i < top:
                    top = i
                if i > bottom:
                    bottom = i
                if j < left:
                    left = j
                if j > right:
                    right = j
    return top, bottom, left, right


def row_widths(grid):
    top, bottom, left, right = bbox(grid)
    widths = []
    for i in range(top, bottom + 1):
        count = 0
        for ch in grid[i]:
            if ch == "1":
                count += 1
        widths.append(count)
    return widths


def is_increasing(widths):
    for i in range(len(widths) - 1):
        if widths[i] > widths[i+1]:
            return False
    return True


def classify(top_width, widths):
    if top_width >= 10:
        return "正五边形"
    if is_increasing(widths):
        return "等腰三角形"
    return "圆形"


for name in ["图形1.txt", "图形2.txt", "图形3.txt"]:
    grid = read_grid("数据/" + name)
    widths = row_widths(grid)
    label = classify(widths[0], widths)
    print(name + "  识别为: " + label)
```
