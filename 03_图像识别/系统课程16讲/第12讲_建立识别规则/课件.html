把特征变成类别
规则
首行宽 >= 10
五边形的顶部是平的，首行很宽。
再看行宽
行宽一直增加
三角形的宽度从顶点到底边越来越大。
默认
否则 → 圆形
圆的宽度先增后减，首行又很窄。
if 首行宽 >= 10: 五边形
elif 行宽增加: 三角形
else: 圆形
规则要能解释；不能只说“程序猜的”。

规则函数



  
def classify(top_width, widths):
    if top_width >= 10:
        return "正五边形"
    if is_increasing(widths):
        return "等腰三角形"
    return "圆形"

print(classify(1, [1, 20, 1]))
print(classify(1, [1, 20, 40]))
print(classify(43, [43, 67, 30]))

  
运行结果
圆形
等腰三角形
正五边形
  • 先判断首行宽，信号最强。
  • 再判断行宽是否一直增加。
  • 剩下的默认是圆形。

规则设计的常见错误

顺序反了五边形被当成三角形
只看 3 个样例过拟合
没有默认情况遇到新形状没有输出
先检查首行宽阈值，再看行宽增加条件，最后看默认分支。

  
报错三步
  1. 看行号：哪一行出问题
  2. 看条件顺序：强特征是否先判断
  3. 看测试集：有没有换新样例

规则、训练与测试


规则系统
人写条件，程序按条件判断。
训练集
用来调规则的样例。
测试集
用来检验规则的新样例；只看训练集容易过拟合。


快问 1
人工规则与机器学习的主要区别？
A. 规则由人写，机器学习从数据中学　B. 完全相同　C. 规则不需要数据　D. 机器学习不需要数据
看答案
A。规则系统由人写条件，机器学习从数据中学习。
快问 2
只在 3 个样例上表现好，换新样例就错，叫什么？
A. 泛化好　B. 过拟合　C. 数据清洗　D. 分辨率高
看答案
B。过度贴合少量样例就是过拟合。


先调规则，再用变体测试；不要用 3 个样例把自己骗了。
