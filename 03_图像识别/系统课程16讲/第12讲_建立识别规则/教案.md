## 教学目标

学完本课，学生应能：

1. 用首行宽和行宽序列写出三条分类规则。
2. 用 classify(top_width, widths) 封装规则。
3. 在 3 个样例和 6 个变体上测试规则。
4. 说出规则系统与机器学习的区别，理解训练集、测试集和过拟合。

## 重点与难点

- **重点：**规则顺序；`top_width >= 10`；`is_increasing(widths)`；默认分支。
- **难点：**阈值是经验值；只看 3 个样例容易过拟合；条件顺序影响结果。
- **突破办法：**先看特征表，再让学生用自然语言说规则，最后翻译成 if/elif。

## 40 分钟流程

### 0–5 分钟：复习与预测（课件 1–3）

1. 复习第 11 课：面积、外接框、填充率、行宽序列。
2. 投影三个样例的特征表，提问：“只看这些数字，怎样把三个类别分开？”
3. 让学生先用自然语言说规则，再写成 if/elif。
4. 强调：规则要能解释，不能只说“程序猜的”。

### 5–13 分钟：讲解与演示（课件 4；出错时切到 7）

1. 首行宽：五边形 43，圆形和三角形都是 1。
2. 行宽是否一直增加：三角形是，圆形和五边形不是。
3. 规则顺序：先判断首行宽，再判断行宽增加，最后默认圆形。
4. 现场演示 `demo1_rule.py`；故意把顺序反过来，观察五边形被误判。
5. 说明阈值 10 是经验值，来自样例和变体测试，不是唯一答案。

### 30–37 分钟：人工智能知识与客观题（课件 6、8）

先用 3 分钟讲规则与机器学习：

> 规则系统由人写条件，能解释；机器学习从数据中学习，通常需要更多数据。只用 3 个样例调规则，很容易过拟合；要用平移、缩放等新样例测试。我们的规则在 3 个原图和 33 个平移/缩放变体上测试，36 个全部正确；但旋转、空心图形还没有验证。

再做 2 道题：

- 人工规则与机器学习的区别？答案 A。
- 只看 3 个样例、换新样例就错叫什么？答案 B（过拟合）。

## 板书设计

```text
建立识别规则
if 首行宽 >= 10:
    正五边形
elif 行宽一直增加:
    等腰三角形
else:
    圆形

圆形     三角形    五边形
首行宽 1   1        43
行宽增 否  是        否

训练集调规则，测试集验规则
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| 五边形被判断成三角形 | 先判断了行宽增加 | 先判断首行宽 >= 10 |
| 换个大小就错 | 阈值只贴合 3 个样例 | 用缩放变体测试，记录适用范围 |
| 新形状没有输出 | 缺少默认分支 | 最后写 `return "圆形"` 或“未知” |
| 只看 3 个样例 | 过拟合 | 增加平移、缩放变体测试 |

## 参考答案

### 客观题

| 题号 | 答案 | 解析 |
|---:|---|---|
| 1 | A | 规则系统由人把条件写清楚；机器学习从训练数据中学习参数或模式。 |
| 2 | B | 用来检验规则效果的新样例是测试集；调规则用的样例是训练集。 |
| 3 | B | 规则过度贴合少量样例，不能适应新数据，就是过拟合。 |
| 4 | A | >= 表示大于或等于，10 本身也满足条件。 |
| 5 | A | elif 是 else if 的缩写，前面的条件不成立时才继续判断。 |
| 6 | A | 规则由人写清楚，属于规则系统；它不是从数据中训练出来的。 |

### 任务 1：规则函数

```python
def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid


def count_ones(grid):
    total = 0
    for row in grid:
        for ch in row:
            if ch == "1":
                total += 1
    return total


def bbox(grid):
    top = len(grid)
    bottom = -1
    left = len(grid[0])
    right = -1
    for i in range(len(grid)):
        for j in range(len(grid[i])):
            if grid[i][j] == "1":
                if i < top:
                    top = i
                if i > bottom:
                    bottom = i
                if j < left:
                    left = j
                if j > right:
                    right = j
    return top, bottom, left, right


def row_widths(grid):
    top, bottom, left, right = bbox(grid)
    widths = []
    for i in range(top, bottom + 1):
        count = 0
        for ch in grid[i]:
            if ch == "1":
                count += 1
        widths.append(count)
    return widths


def is_increasing(widths):
    for i in range(len(widths) - 1):
        if widths[i] > widths[i+1]:
            return False
    return True

def classify(top_width, widths):
    if top_width >= 10:
        return "正五边形"
    if is_increasing(widths):
        return "等腰三角形"
    return "圆形"

print(classify(1, [1, 20, 1]))
print(classify(1, [1, 20, 40]))
print(classify(43, [43, 67, 30]))
```
