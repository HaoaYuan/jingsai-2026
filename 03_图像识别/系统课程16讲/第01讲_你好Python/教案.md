## 教学目标

学完本课，学生应能：

1. 独立打开 IDLE，新建、保存并运行一个 `.py` 文件。
2. 写出 `print("...")`，用 `#` 写注释，说出括号和引号必须用英文符号。
3. 认出 `SyntaxError`（中文符号、引号不成对）和 `NameError`（大小写错误），按“行号 → 红字 → 符号”检查。
4. 说出人工智能与图像识别的基本关系，举例说明 1–2 个生活应用。
5. 知道比赛现场不能上网、不能安装大模型、不能提前保存代码，只能带空白 U 盘。

## 重点与难点

- **重点：**`print()` 的写法；先保存再按 F5；一行 `print` 输出一行字。
- **难点：**中英文符号不分；看到报错就慌；文件没有保存成 `.py`。
- **突破办法：**教师故意写错一次，全班一起读报错；每个学生至少独立改对一个符号错误。

## 40 分钟流程

### 0–5 分钟：导入与预测（课件 1–3）

1. 投影 `数据/导入_像素菱形.txt`，先不解释，提问：
   - “你看到了什么形状？”
   - “如果把这张图交给计算机，它看到的是什么？”
2. 揭示：人看到菱形，计算机看到的是 `0` 和 `1`。图像识别就是让计算机从这些数字里找规律，判断它是什么。
3. 连接比赛：初中组现场题会给出 `图形1.txt`–`图形3.txt`，每个文件都是 `0/1` 网格，要求判断圆形、正五边形、等腰三角形。今天先学会让计算机说话，后面再让它看图。
4. 预测：投影 `print("你好，世界")`，提问“运行后屏幕上会出现什么？引号会不会显示？”让学生先说出预测，再运行验证。
5. 板书本课目标：**运行程序、输出文字、认出常见错误。**

### 5–13 分钟：讲解与演示（课件 4–6；出错时切到 9）

教师现场操作，学生只看不敲，避免掉队。

1. **程序是什么：**程序就是给计算机的菜谱，一步一步写清楚，计算机照着做，不会自己猜。
2. **认识 IDLE：**
   - Shell：对话窗口，敲一行、回车、马上回答，适合试一小句。
   - 编辑器：`File → New File`，写完整程序，保存成 `.py`，按 `F5` 运行。
3. **完整操作顺序：**
   - 开始菜单搜索 IDLE；
   - `File → New File`；
   - 写代码；
   - `Ctrl+S` 保存，文件名用 `hello.py`；
   - 按 `F5` 运行；
   - 看 Shell 里的输出。
4. **解剖第一个程序：**

   ```python
   print("你好，世界")   # 在屏幕上显示一行字
   ```

   - `print` 是计算机的“嘴巴”，必须全小写；
   - `()` 是英文括号，里面放要说的话；
   - `""` 是英文引号，必须成对，引号本身不显示；
   - `#` 后面是注释，写给人看，计算机会跳过。
5. **故意犯错：**把 `print` 改成 `Print`，运行，投影 `NameError`。带学生读最后一行红字，再改回来。强调：报错不是失败，是计算机在告诉你哪一行有问题。

### 30–37 分钟：人工智能知识与客观题（课件 10）

先用 3 分钟讲，再做 2–3 道题。

**讲稿：**

> 人工智能是让计算机完成原本需要人脑的任务：看、听、说、判断。图像识别是其中的“看”：输入一张图，输出它是什么、有什么。生活里的刷脸解锁、车牌识别、零件质检都用到了它。
>
> 比赛里的图形识别没有大模型，也不需要联网。它就是一段你写的程序：读入 `0/1` 网格，提取特征，按规则判断形状。它不是魔法，是人写的程序。今天先学会让程序说话，后面每一步都会接到这个任务上。

**当堂题：**

## 板书设计

```text
我的第一个程序
print("你好，世界")
  ↑小写   ↑英文括号   ↑英文引号成对
# 注释：给人看的，计算机跳过

保存 → F5
报错三步：看行号 → 看红字 → 查符号
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `SyntaxError: invalid character` | 用了中文引号、括号或逗号 | 把输入法切到英文，再重新打符号 |
| `NameError: name 'Print' is not defined` | `print` 大小写错 | Python 区分大小写，`print` 全小写 |
| `SyntaxError: unterminated string literal` | 引号只打了一半 | 引号要成对，像一双筷子，少一只就夹不住菜 |
| 改了代码，输出没变 | 没保存就按了 F5 | 先 `Ctrl+S`，再 `F5` |
| 文件打不开或不是 Python 文件 | 保存成了 `.txt` | 文件名写 `01_自我介绍.py`，保存类型选“所有文件” |
| `IndentationError` | 行首多了空格 | 把行首空格删掉，顶格写 |
