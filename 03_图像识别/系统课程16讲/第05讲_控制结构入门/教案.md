**使用时机：** 本课为正式第 5 课，安排在第 2 周，紧接第 4 课《小数之谜》、在第 6 课《让程序判断》之前，作为「分支、循环、逻辑运算符」的第一次整体接触。本课只要求「见过、会照着写、能说出走哪条路」，不要求迁移到图形识别；第 6、7 课会分别把分支和循环放到 0/1 像素情境里讲深、练透，第 07 讲补充《边数边判》再作综合巩固。

**与前后课的分工：**

- 本课：生活情境，三种结构一起认全；`if/elif/else`、`for ... in range()`、`and/or/not` 各见一次。
- 第 6 课：比较运算、`==` 与 `=`、冒号缩进、按图形特征分类（讲深）。
- 第 7 课：`for` 逐字符检查、计数器、变量联动（讲深）。
- 第 07 讲补充《边数边判》：if + for 综合巩固（学完之后）。

## 教学目标

学完本课，学生应能：

1. 说出程序有三种走法——顺序、分支、循环，并各举一个生活例子。
2. 用 `if / elif / else` 写一个三段判断（门票），说出「条件成立才走这一条」。
3. 用 `for n in range(1, 11):` 写出重复执行，说出循环体每轮做的事。
4. 用 `and`（都成立）、`or`（至少一个）、`not`（取反）写组合条件，能预测 `and` 条件下程序的输出。
5. 认出漏冒号、没缩进、`=` 与 `==` 混用、把 `and` 写成 `&&` 四类常见错误。

## 重点与难点

- **重点：** 分支「选一条路」与循环「转一圈」的区别；`and` 与 `or` 的含义。
- **难点：** 「只执行一次」和「执行很多次」分不清；把 `and` 理解成「或者」；循环体缩进层级。
- **突破办法：** 用「门票一次判断」对比「报数 10 次」；投影逐轮表看见 n 在变；两张口诀卡上黑板（分支选一条，循环转一圈／and 全对才对）；任务分三档，选做不占统一进度。

## 40 分钟流程

### 0–5 分钟：复习与预测（课件 1–3）

1. 一句话复习第 4 课：小数比较不能只写 `==`，要看差值。
2. 提问：「到目前为止，我们的程序都是从上往下、一句一句执行。生活里有没有『看情况办』和『重复做』的事？」收集：看身高买票、按成绩分等级、点名报数、每天测温。
3. 投影第 3 页那段「看身高买票」的代码，**只猜不运行**，全班对 A/B/C/D 举手投票，把人数记在黑板角。
4. 板书本课三件东西：分支、循环、逻辑运算符。

### 5–13 分钟：讲解与演示（课件 4–9；易错点见第 6 页）

1. **三种走法（约 2 分钟）：** 顺序（一句一句往下走）、分支（选一条）、循环（转一圈）。用「进游乐园」串起来：走到门口（顺序）→ 看身高决定票种（分支）→ 10 个同学依次做同样的检查（循环）。
2. **分支（约 3 分钟）：** 运行 `demo1_门票判断.py`。`height = 135`，先比 120、再比 150，输出「半票」。现场把 `height` 改成 110 → 免票、改成 160 → 全票，同一段代码走不同分支。强调 `if 条件:` 的英文冒号、下一行 4 个空格缩进、`=` 赋值与 `==` 比较。
3. **循环（约 2 分钟）：** 运行 `demo2_报数循环.py`，`for n in range(1, 11):` 打印 1–10。投影逐轮表：第 1 轮 n=1、第 2 轮 n=2……点明「循环体被重复执行了 10 次」。
4. **合起来（约 2 分钟）：** 运行 `demo4_循环里判断.py`，把 `if` 放进 `for` 里，只喊 3 号及以后的同学。点明「判断写在循环里就会执行很多次」。
5. **逻辑运算符（约 4 分钟）：** 运行 `demo3_逻辑运算.py`。游乐园要求「身高 ≥ 140 **并且** 年龄 ≥ 12」才能坐过山车 → `and`；「下雨 **或者** 刮大风就改室内」→ `or`；「**没**带学生证就不能借书」→ `not`。对照表上黑板，强调 Python 用单词，不写 `&&`、`||`、`!`。

### 30–37 分钟：人工智能知识与客观题（课件 11）

先用 3 分钟讲「规则」：

> 刚才的 `if height < 120:` 就是一条规则：人先把「什么情况对应什么结果」写清楚，程序照着做。把很多条规则组合起来判断，这样的系统叫**规则系统**，是人工智能最早的做法之一。它的好处是每一步都能解释；缺点是规则要人一条条写。规则一定只能由人写吗？第 12 课会讲：也可以让机器从数据里自己学，那叫机器学习。

再做 2 道快问（答案在演讲者备注，投影页不显示）：

- 「程序按人事先写好的条件做判断」叫什么？答案 A（规则系统）。
- 「下雨 **或者** 刮风就改室内」该用哪个？答案 B（`or`）。

然后让学生打开 `练习.html`，完成教师指定的 2–3 道客观题（建议第 1、3、5 题），提交后看解析；填空题即时判分，答错可重做。

## 板书设计

```text
控制结构入门：让程序会选、会重复

三种走法
顺序：一句一句往下走
分支：if / elif / else —— 看情况选一条（只走一条）
循环：for n in range(1, 11): —— 同一件事重复做

if 条件:        ← 英文冒号
    缩进 4 格    ← 属于这一条路
= 赋值   == 比较

逻辑运算符
and  两个都成立
or   至少一个成立
not  反过来

口诀：分支选一条，循环转一圈，and 全对才对
```

## 常见错误与纠正

| 现象 | 原因 | 纠正话术 |
|---|---|---|
| `SyntaxError: expected ':'` | `if` / `for` 条件后漏冒号 | 条件后面补英文冒号 `:` |
| `IndentationError` | 循环体／分支体没缩进，或空格数不一致 | 同一层统一 4 个空格 |
| 条件永远成立或报 `SyntaxError` | 把 `=` 写成比较 | 一个 `=` 是赋值，两个 `==` 才是比较 |
| 写 `h >= 140 && a >= 12` 报错 | 用了其它语言的符号 | Python 用单词 `and` / `or` / `not` |
| 循环只打印最后一个数 | `print` 没缩进进循环体 | 要重复做的事必须缩进到 `for` 里面 |
| 把 `and` 当成「或者」 | 混淆「都成立」与「至少一个」 | `and` 要两边都对，`or` 只要一边对 |
| 三条路都执行了 | 三个 `if` 并列，没用 `elif` 连起来 | 互斥的情况用 `elif` / `else` 串成一条链 |

### 任务 1：门票几价

```python
height = 135  # 单位：厘米

if height < 120:
    print("免票")
elif height < 150:
    print("半票")
else:
    print("全票")
```

输出：`半票`

### 任务 2：哪些编号能上台

```python
for n in range(1, 11):
    if n >= 4 and n <= 7:
        print(n)
```

输出：

```text
4
5
6
7
```

### 任务 3：谁需要补测（选做）

```python
for n in range(1, 11):
    if n < 3 or n > 8:
        print("补测:", n)
```

输出：

```text
补测: 1
补测: 2
补测: 9
补测: 10
```

也可写成 `if not (n >= 3 and n <= 8):`，但 `not` 与括号的组合作为拓展，不要求全体掌握。
