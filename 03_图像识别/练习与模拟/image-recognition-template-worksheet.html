1读取点阵 · 先存一行，再存整张图

import numpy as np


def read_grid(path):
    grid = []
    with open(path, encoding="utf-8") as file:
        for line in file:
            line = line.strip()
            if line:
                row = []
                for pixel in line:
                    row.append(int(pixel))
                grid.append(row)
    return np.array(grid, dtype=int)

代码解析

grid.append([int(pixel) for pixel in line]) 是上面三步的短写法。方括号里先做出一行整数，外面的 grid.append() 再把这一行存起来。点「下一步」，看 line、row 和 grid 各在什么时候变化。

row = [] 每读一行都要重新创建。grid.append(row) 放在内层循环后面，等这一行的像素都转完，才添加一次。

完整的 read_grid() 用 with open(...) 打开文本，读完后自动关闭。if line 检查清理后的文本是否有内容，最后用 return 把读好的数组交给调用者。

数学原理 · 像素的行列坐标

把图像看成一个由 0、1 组成的矩形表格。每个像素的位置用「行下标，列下标」表示，第一个下标是行，第二个是列。

示例读完后有 2 行、3 列，记作 (2, 3)。因为下标从 0 开始，grid[1, 1] 取的是第 2 行、第 2 列，值为 1。沿固定顺序存数据，才能根据坐标找回原来的像素。

自测：只含 0 的一行会被跳过吗？

strip() 去掉换行和两端空白。空行会变成空字符串，但 "000" 仍有三个字符，表示三个背景像素，应存入点阵。

def features(grid):
    widths = []
    for row in grid:
        width = np.count_nonzero(row)
        if width > 0:

代码解析

点阵只含整数 0、1，所以 np.count_nonzero(row) 就是在数这一行的 1。这段程序跳过宽为 0 的行，留下本题图形的有效行。

从下标 1 开始才能和上一行比较。四行只有三对相邻行，相等时不算变窄。分母用 max(1, len(widths) - 1)，是为了只有一行时仍能算出 0。

数学原理 · 用比例描述形状

一行里每个前景像素贡献 1，把这一行的 0、1 加起来，就得到前景像素数。本程序把这个数记作行宽，再用最宽一行作分母，把像素数量换成比例。

手算示例 widths = [2, 4, 4, 3]

  1. 第 1 行2
  2. 第 2 行4
  3. 第 3 行4
  4. 第 4 行3，变窄

顶行宽度比例顶行 ÷ 最宽行 = 2 ÷ 4= 0.5

平均宽度比例平均行宽 ÷ 最宽行 = 13 ÷ (4 × 4)= 0.8125

变窄比例变窄次数 ÷ 比较次数 = 1 ÷ 3≈ 0.333

想一想：每个像素横向展开成两格，三个比例会变吗？

行宽变成 [4, 8, 8, 6]。顶行、平均行宽和最宽行都乘了 2，前两个比例保持相同。相邻行的大小关系也一样，因此变窄比例仍是 1 ÷ 3。

3比对模板 · 差值越小，特征越接近

def identify(grid, library):
    target = features(grid)
    if target is None:
        return "无法识别"

    best_name = "无法识别"
    best_distance = float("inf")

            continue

代码解析

library 是「模板名称 → 点阵」的字典。待测图提取一次特征，然后依次与每个模板比较。

abs() 取绝对值，让正差和负差都按实际差距累加。每比一个模板，distance 都要重新从 0 开始。

先用 float("inf") 把最小差值设成正无穷，第一个有效模板就能更新它。以后只要找到更小的差值，就同时记下差值和模板名。如果某个模板的特征是 None，用 continue 去比较下一个。

数学原理 · 把三项距离加起来

三项特征的范围都是 0 到 1。比较时，每一项都做「待测值减模板值」并取绝对值，再把三项相加。这样，偏大和偏小的差距都计入总分。

特征待测图模板 A相差

试着比较模板 B：第一项差值是 0.5 − 0.75 = −0.25，计入总分的是 0.25。切回模板 A，比较两个总差值，找出更接近的模板。

数学原理 · 根据特征做分类

三个比例把一张图压成三个数字。每个模板都得到一个总差值，程序找其中最小的一个，并输出它对应的类别。不同图形可能碰巧得到相同的特征，这时仅靠这三个数无法分开它们。
