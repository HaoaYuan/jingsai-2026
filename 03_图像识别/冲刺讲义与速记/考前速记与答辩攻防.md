### 【正面】27 行必背代码与逐行口诀

```python
# ① 读入网格（8行）：开文件、逐行读；去空白、跳空行；装进列表再返回
def load(name):
    grid = []
    with open("data/" + name, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid

# ② 计算行宽（9行）：先找有 1 的行，首行数到尾行，count 数宽度
def row_widths(g):
    rows = []
    for r in range(len(g)):
        if "1" in g[r]:
            rows.append(r)
    widths = []
    for r in range(rows[0], rows[-1] + 1):
        widths.append(g[r].count("1"))
    return widths

# ③ 判定规则（8行）：顶宽够 10 是五边；宽度变小是圆；都不满足三角形
def classify(widths):
    if widths[0] >= 10:
        return "正五边形"
    for i in range(len(widths) - 1):
        if widths[i] > widths[i + 1]:
            return "圆形"
    return "等腰三角形"

# ④ 主程序（3行）：1 到 3 拼名字；两个空格、英文冒号
for i in (1, 2, 3):
    name = "图形" + str(i) + ".txt"
    print(name + "  识别为: " + classify(row_widths(load(name))))
```

**实测标准输出（逐字符对照）：**
```text
图形1.txt  识别为: 圆形
图形2.txt  识别为: 等腰三角形
图形3.txt  识别为: 正五边形
```
*(注意：文件名后**两个空格**，英文冒号 `识别为:` 后面**一个空格**)*

#### 1. 流程图四种标准框形
- **圆角矩形**：开始 / 结束
- **平行四边形**：输入 / 输出（如：`输入 图形N.txt` / `输出 识别为: 圆形`）
- **矩形**：处理操作（如：`计算外接框行宽列表 widths`）
- **菱形**：条件判断（分支必须标出 **“是”** 或 **“否”**）

#### 2. 一分钟答辩标准话术（背诵骨架）
> “各位评委老师好！我们的程序分为四个步骤：
> 1. **读取**：用 `open()` 逐行读取 `data` 文件夹中的网格，`strip()` 过滤换行和空行；
> 2. **特征提取**：定位图形的上下边界，统计外接框内**每一行的像素宽度**；
> 3. **规则分类**：若顶部行宽 $\ge 10$ 判为**正五边形**；若行宽中途出现变小判为**圆形**；行宽只增不减判为**等腰三角形**；
> 4. **模板输出**：严格按照题目要求的格式打印结果。
> 我们的规则在 3 个原图及 33 个平移缩放变体（共 36 个样例）上达到了 **100% 准确率**。适用的边界是正向摆放的实心二值图，旋转和空心图形不在本次规则范围内。”

### 教师评分细则（满分 20 分）
1. **框形规范（6 分）**：起止框用圆角矩形（2分）、输入输出用平行四边形（2分）、处理用矩形与判断用菱形（2分）。混淆框形扣 2~4 分。
2. **分支逻辑完整（8 分）**：菱形判断必须有两条出边，并清晰标明 **“是”** 和 **“否”**；循环回流箭头清晰。
3. **与代码一致性（6 分）**：判定顺序必须是“先顶宽 $\ge 10$ → 再行宽变小 → 否则三角形”，若与提交代码顺序不符扣 3~6 分。

# 第三部分 答辩攻防：评委最常问的 5 大死穴

如果被抽中答辩，评委最喜欢通过追问细节来检验代码是不是学生自己写的，还是死记硬背的。请让学生反复演练以下 5 个回答：

---

### 问题 1：为什么五边形要先判？如果把圆形先判会发生什么？
- **错误回答**：“老师教我们这么写的 / 随便排的顺序。”
- **标准回答**：
  > “报告评委老师，**必须先判正五边形**。
  > 因为从真实网格数据分析，正五边形顶上是一条宽平边（真题顶宽达到 43 个像素），但从顶部到底部也是‘先变宽、后变窄’的，它的行宽序列**同样存在变小的段落**。
  > 如果把圆形判据（行宽变小）放在前面，正五边形就会被误判成圆形！所以必须利用五边形独特的‘顶部平边（顶宽 $\ge 10$）’先将其筛选出来，剩下的图形里只有圆形才会行宽变小。”

---

### 问题 2：你们为什么不用 OpenCV 或深度学习（CNN / 卷积神经网络）来识别？
- **错误回答**：“因为我们不会 OpenCV / 深度学习太难了。”
- **标准回答**：
  > “报告评委老师，这主要是基于**竞赛环境限制与计算效率**两个考量：
  > 第一，比赛考场是离线环境，禁止联网，官方电脑只有纯净的 Python 标准库环境，没有安装第三方视觉库；
  > 第二，我们面对的是由 0 和 1 构成的二值网格，形状规则、类别明确。采用‘提取外接框行宽剖面’的规则系统，只需要 27 行代码、毫秒级即可精确识别，计算复杂度远低于深度学习，且具有 100% 的**可解释性**。”

---

### 问题 3：如果评委把图形旋转了 45 度或者 90 度，你们的代码还能识别吗？
- **错误回答**：“能，肯定能识别！”（夸大直接被评委当场出题打脸）
- **标准回答**：
  > “报告评委老师，**这套行宽规则主要是针对正向摆放图形设计的**。
  > 如果旋转 90 度，三角形和五边形在特定角度下行宽趋势会发生改变，这套基于水平行宽的规则可能会失效。
  > 如果需要支持任意角度旋转，我们进阶储备了**‘基于 Moore 邻域的轮廓跟踪与转角曲率分析算法’**：沿着图形边界提取有序外轮廓，计算相邻向量夹角数出拐点数量。圆形的拐角数为 0，三角形为 3，五边形为 5，这种角点特征具备旋转不变性。但在本次提交中，为确保在考场有限时间内绝对稳定，我们选用了最简洁、验证最充分的行宽规则。”

---

### 问题 4：如果图像有噪点（比如背景里有孤立的 1，或者图形中间有空洞），程序会怎样？怎么改进？
- **错误回答**：“不知道，题目说没有噪点。”
- **标准回答**：
  > “如果背景存在孤立噪点，外接框边界（`rows[0]` 和 `rows[-1]`）可能会被拉大，导致行宽统计受影响。
  > 改进方法非常明确：可以在预处理阶段加入一个**连通域滤波**或**面积阈值过滤**，用 BFS（广度优先搜索）找出最大的连通块，忽略掉小于 5 个像素的孤立噪点；对于内部空洞，由于我们统计的是整行 1 的累计数量，轻微空洞不会破坏整体行宽‘变宽或变窄’的单调趋势，程序具有一定的容错度。”

---

### 问题 5：为什么顶宽阈值定为 10，而不是 5 或者 20？这个数字是怎么来的？
- **错误回答**：“我猜的。”
- **标准回答**：
  > “报告评委老师，这个阈值是**在训练数据上实验确定的**。
  > 在 100×100 的网格中，等腰三角形和圆形的顶部都是从顶点或圆弧最高点开始，真题实测第一行宽度只有 1 个像素（即使在缩放 0.7 倍变体中也不超过 2 个像素）；而正五边形顶边是一条完整的边，实测宽度达到 43 个像素（0.7 倍缩放后依然在 30 像素以上）。
  > 阈值设为 10，既远远高于三角形和圆形的顶部宽度（1~2），又远远低于五边形的顶部宽度（30~43），留出了极大的安全裕度，在平移和缩放变体测试中实现了 100% 的容错区分。”
