## 第 1 段 load：把文件读成网格（8 行）

```python
def load(name):
    grid = []
    with open("data/" + name, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                grid.append(line)
    return grid
```

**口诀：开文件、逐行读；去空白、跳空行；装进列表再返回。**

| 行 | 这行在干嘛 |
|---|---|
| `def load(name):` | 定义函数，参数是文件名 |
| `grid = []` | 先准备一个空列表装结果 |
| `with open(...) as f:` | 打开 `data/图形N.txt`，用完自动关 |
| `for line in f:` | 一行一行读 |
| `line = line.strip()` | **必须**去掉行尾换行符和空格 |
| `if line:` | 空行跳过（空字符串是假） |
| `grid.append(line)` | 装进列表 |
| `return grid` | 把结果交出去 |

**易错**：忘 `strip()`（列数会多出看不见的字符）；忘 `data/` 前缀（找不到文件）；`if line:` 后忘冒号。

## 第 2 段 row_widths：数出每行宽度（9 行）

```python
def row_widths(g):
    rows = []
    for r in range(len(g)):
        if "1" in g[r]:
            rows.append(r)
    widths = []
    for r in range(rows[0], rows[-1] + 1):
        widths.append(g[r].count("1"))
    return widths
```

**口诀：先找有 1 的行，首行数到尾行，count 数宽度。**

| 行 | 这行在干嘛 |
|---|---|
| `rows = []` + 循环 + `if "1" in g[r]:` | 找出所有"有 1"的行号，第一个是顶、最后一个底 |
| `range(rows[0], rows[-1] + 1)` | 从图形第一行数到最后一行（`+1` 是因为 range 不含尾） |
| `g[r].count("1")` | 这一行里 1 的个数 = 这一行宽度 |
| `return widths` | 宽度列表，如圆形：1, 17, 23, …, 17, 1 |

**易错**：`rows[-1] + 1` 忘 `+1`（少一行）；两处 `g[r]` 写错成 `g`；`count("1")` 的引号。
**补充**：忘记 `count` 时用循环数也行（教程第 5 章写法），功能一样。

## 第 3 段 classify：三条规则定分类（8 行）

```python
def classify(widths):
    if widths[0] >= 10:
        return "正五边形"
    for i in range(len(widths) - 1):
        if widths[i] > widths[i + 1]:
            return "圆形"
    return "等腰三角形"
```

**口诀：顶宽够 10 是五边；宽度变小是圆；都不满足三角形。**

| 行 | 规则 | 为什么 |
|---|---|---|
| `if widths[0] >= 10:` | 第一行（顶）就有 10 格以上宽 → 正五边形 | 五边形顶上是一条平边（真题顶宽 43） |
| `if widths[i] > widths[i + 1]:` | 行宽中途变小过 → 圆形 | 圆先鼓起来再收回去 |
| `return "等腰三角形"` | 宽度只增不减 → 等腰三角形 | 从顶尖越往下越宽 |

**顺序不能换**：五边形的行宽也有变小段，先判圆会把五边形吃掉。答辩必背："规则在正向实心图形、平移 ±10、缩放 0.7–1.2 内 36 个样例全对；旋转、空心没验证。"

## 第 4 段 主程序：循环三件套按模板输出（3 行）

```python
for i in (1, 2, 3):
    name = "图形" + str(i) + ".txt"
    print(name + "  识别为: " + classify(row_widths(load(name))))
```

**口诀：1 到 3 拼名字；两个空格、英文冒号。**

**模板逐字对照（丢一个字符就丢分）：**

```text
图形1.txt  识别为: 圆形
图形2.txt  识别为: 等腰三角形
图形3.txt  识别为: 正五边形
```

文件名后**两个空格**、`识别为:` 用**英文冒号加一个空格**、类别不带书名号引号。

## 高频错误十条（默写卡壳先查这里）

| # | 症状 | 病根 |
|---|---|---|
| 1 | `SyntaxError` | 中文引号、中文括号、漏冒号 |
| 2 | 判断永远不走对分支 | `=` 写成了赋值，比较要 `==` |
| 3 | `NameError: name 'grid' is not defined` | 忘了 `grid = []` 初值 |
| 4 | 缩进乱 | if 体 / for 体缩进 4 格，return 与 for 对齐 |
| 5 | 列数变成 101 或比较出怪结果 | 忘 `strip()` |
| 6 | `FileNotFoundError` | 路径没写 `data/` 或名字拼错 |
| 7 | 行数不对 | 忘跳空行（`if line:`） |
| 8 | 少最后一行宽度 | `rows[-1] + 1` 忘 `+1` |
| 9 | 五边形被判成圆形 | classify 三条规则顺序换了 |
| 10 | 输出分被扣 | 模板空格数、英文冒号、类别字错 |
